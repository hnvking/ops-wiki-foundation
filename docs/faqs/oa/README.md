# OA 系统 FAQ

本目录收录 OA 系统 的运维问题。所有问题按「系统 → 表单」两级归档：

1. 系统目录：`docs/faqs/oa/`；
2. 表单目录：每个表单一个子目录，问题文件只能放进对应表单目录。

新增问题时在 frontmatter 填写 `related_system: OA 系统` 与 `related_form: <表单标识>`，并保存到 `faqs/oa/<表单标识>/<问题>.md`。
