# 月度申购自然村关联不到需删单重做

## 问题描述

业务同事反馈：黄略镇殷屋村委会北青、附城镇老村村民委员会下村。在月度申购里自然村关联不到、业务同事帮忙处理一下

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 采购、申购相关岗位
- **影响数据:** 相关单据与流程数据

## 原因分析

- 数据异常：月度申购中自然村关联不到时需删除申购汇总单重新做；单据已审批完后无权限则只能删单重做并重新发申购单。

## 解决方案

1. 月度申购中自然村关联不到时需删除申购汇总单重新做
2. 单据已审批完后无权限则只能删单重做并重新发申购单 IT 运维组答复月度申购汇总单得删掉重新做，IT 运维组反馈单据已审批完没权限，IT 运维组明确只能删单重做并重新发一个申购单

## 预防措施

- 审批完成后的单据需删单重做。
- 在流程说明中明确相关规则，避免重复咨询。
