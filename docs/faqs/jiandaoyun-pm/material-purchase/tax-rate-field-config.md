# 税率字段配置与同步

## 问题描述

PM 系统内多个表单的税率字段存在配置或同步问题：材料采购订单的税率带不过对账流程；提料单缺少税率字段；调拨单税率未同步至材料明细；入库单税率字段取值不一致导致 NC 计算错误。

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 物资、采购、对账相关岗位
- **影响数据:** 税率无法正确带出，影响对账与 NC 计算

## 原因分析

- 税率字段在部分表单（如提料单）中缺失，或未设置为自动带出。
- 税率字段取值来源不一致：暂估与非暂估共用同一税率字段，税率需由合同带出。
- 税率字段未同步至下游材料明细，导致对账流程无法取到税率。

## 解决方案

1. **提料单：** 新增税率字段，通过订单发起的提料单可自动带出税率；历史单据需手动补录，为相关用户开放修改权限。
2. **调拨单：** 将调拨单税率改为必填，并设置接口同步至材料明细；同主体调拨税率设为 0，不同主体设为必填。
3. **材料采购订单：** 税率字段改为必填并开放权限供用户自行修改；次日处理税率带不过对账流程的问题。
4. **入库单：** 统一税率字段取值逻辑，暂估取值由内部开发负责，无需额外代码实现。
5. **暂估取值接口：** 税率字段由合同带出，暂估与非暂估共用同一税率字段，避免因税率不一致导致 NC 计算错误。

## 预防措施

- 新增税率字段时同步检查下游引用表单（对账、明细）的带出规则。
- 同一字段的取值来源（合同带出 / 手动填写）在相关表单间保持一致。
- 历史单据补录税率前先开放对应权限，再执行批量修改。
