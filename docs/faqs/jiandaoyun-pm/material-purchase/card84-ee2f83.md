# 多个申购合并询价定供应商时只能单选申购、需调整表单配置

## 问题描述

业务同事反馈：两个申购合并询价定供应商，7.5.5招标/询价审批这个不能选多个申购吗？

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 采购、申购相关岗位
- **影响数据:** 相关单据与流程数据

## 原因分析

- 配置缺失：系统选择不了多个申购单，需要在申购汇总把需要的材料都做在一个单里；修改方案是把主表的申购单取消必填，直接在明细里选择申购单，明细可以选择多个申购汇总的材料；申购分集采类和非集采类时只能分开。

## 解决方案

1. 系统选择不了多个申购单，需要在申购汇总把需要的材料都做在一个单里
2. 修改方案是把主表的申购单取消必填，直接在明细里选择申购单，明细可以选择多个申购汇总的材料
3. 申购分集采类和非集采类时只能分开 确认当前无法选择多个申购单，按开发说明需在申购汇总把材料做在一个单里
4. 如需支持可把主表申购单取消必填、改为在明细中选择多个申购汇总材料

## 预防措施

- 之前未提过多申购合并询价场景，需修改表单配置。
- 在流程说明中明确相关规则，避免重复咨询。
