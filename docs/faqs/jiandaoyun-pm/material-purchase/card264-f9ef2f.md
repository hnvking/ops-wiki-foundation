# MPS计划订单 编号不显示 采购件 制造件 请购单

## 问题描述

业务同事反馈：陈工，NC运算这两个编号不显示，单独查找也找不到，看看是什么原因，帮忙处理一下，谢谢。

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 采购、申购相关岗位
- **影响数据:** 相关某模块数据

## 原因分析

- 配置缺失：MPS运算生成单据类型由物料库存信息页签的物料类型决定：采购件默认生成请购单，制造件生成生产订单；存在下游请购单时生产订单无法直接删除。

## 解决方案

1. 删除下游请购单→回到MPS计划订单取消完成、取消确认→删除生产订单
2. 将物料类型由采购件改为制造件
