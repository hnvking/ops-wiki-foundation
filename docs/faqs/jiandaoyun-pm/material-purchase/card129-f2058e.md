# 订单关联申购单 编号带不出 单项 多选 反写 字段隐藏 申购编码

## 问题描述

业务同事反馈：订单关联了申购单之后，编号带不出来是什么原因啊

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 采购、申购相关岗位
- **影响数据:** 影响采购订单明细中申购单编号展示及带明细订单导出。

## 原因分析

- 配置缺失：订单关联申购单后编号带不出来的原因是当前只设置单项，明细中选择申购单为多选，反写回来目前没有；申购单编号字段隐藏。

## 解决方案

1. 订单关联申购单后编号带不出来的原因是当前只设置单项，明细中选择申购单为多选，反写回来目前没有
2. 申购单编号字段隐藏。 当前只设置了单项，明细里选申购单是多选但反写回来目前没有
3. 申购单编号字段被隐藏，需在订单明细添加申购单号字段
