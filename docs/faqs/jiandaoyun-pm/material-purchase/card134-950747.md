# 申购单 采购执行人 邓松涛 集采 订单对接人 流程重新激活

## 问题描述

业务同事反馈：[单据编号] 这个申购单，为什么采购执行人是邓松涛在选呢

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 采购、申购相关岗位
- **影响数据:** 影响集采申购单采购执行人选择及订单对接人配置。

## 原因分析

- 配置缺失：集采默认订单对接人；采购任务分配节点上采购执行人由谁担任涉及集采归业务同事还是按项目分人等既有配置；该流程需重新激活重新走到采购任务分配节点。

## 解决方案

1. 集采默认订单对接人
2. 采购任务分配节点上采购执行人由谁担任涉及集采归业务同事还是按项目分人等既有配置
3. 该流程需重新激活重新走到采购任务分配节点。 IT 运维组补充集采默认订单对接人
4. 业务同事梳理该问题属采购任务分配节点既有配置复核，并确认需让流程重新激活重新走到采购任务分配节点

## 预防措施

- 需区分采购执行人由谁选、集采默认订单对接人及节点是否重新激活。
- 在流程说明中明确相关规则，避免重复咨询。
