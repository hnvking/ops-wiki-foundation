# 采购订单关联合同带不出单价、因合同材料明细导入时合同编码缺失

## 问题描述

业务同事反馈：黄经理 这几份合同 只有雨虹 清塑 坤达 三家下单能带出来单价 其他合同都带不了单价 麻烦帮忙看一下

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 采购、申购相关岗位
- **影响数据:** 相关某模块数据

## 原因分析

- 数据异常：材料采购订单单价一直联动的是合同明细单价；合同明细带出回标单价；需查合同明细是否有对应值。

## 解决方案

1. 材料采购订单单价一直联动的是合同明细单价
2. 合同明细带出回标单价
3. 需查合同明细是否有对应值 查明原因是导入合同材料明细时未成功导入对应的合同编码，7.5.12材料采购订单单价联动的是合同明细单价而非回标单价

## 预防措施

- 导入合同材料明细时必须成功导入对应的合同编码，否则订单带不出单价。
- 在流程说明中明确相关规则，避免重复咨询。
