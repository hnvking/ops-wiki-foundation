# 下单测算、供应商多合同、单价冲突

## 问题描述

业务同事反馈：业务同事 现在问题已经搞清楚了，之前的下单测算只支持按供应商的维度测算（之前共识的时供应商只存在一份合同）目前新增需求：一个供应商存在多个合同，如果有都份合同过滤对应的单价有两个方案：1、把旧合同的清单停用，在测算下单时过滤掉旧合同的单价，系统测算操作保持不变2、修改为下单测算按采购合同的方式进行测算，测算时选择具体合同，这个需求需把之前按供应商的逻辑推翻重…

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 采购、申购相关岗位
- **影响数据:** 下单测算表单价取值，涉及同一供应商多份合同场景；每个材料的定标供应商数量可为5、6、7家不等

## 原因分析

- 流程规则不清：原下单测算按供应商维度取单价，前提是同一供应商只存在一份合同；一个供应商存在多份启用合同时会产生单价冲突导致测算单价错误；若两份启用合同材料编码不一致可同步对应合同单价；合同内存在SKU+城市+车型的采购码用于确认单价，测算时应过滤掉不相关单价。

## 解决方案

1. 原下单测算按供应商维度取单价，前提是同一供应商只存在一份合同
2. 一个供应商存在多份启用合同时会产生单价冲突导致测算单价错误
3. 若两份启用合同材料编码不一致可同步对应合同单价
4. 合同内存在SKU+城市+车型的采购码用于确认单价，测算时应过滤掉不相关单价。 明确测算单价错误根因为一个供应商存在多份启用合同导致单价冲突，给出停用旧合同清单或改为按采购合同测算两种方案，并于10月16日告知两份合同单价问题已解决

## 预防措施

- 测算时选择合同作为筛选维度可避免多合同单价冲突；旧合同清单停用后需确认单价过滤生效；改动按供应商取价逻辑需推翻原有系统逻辑。
- 在流程说明中明确相关规则，避免重复咨询。
