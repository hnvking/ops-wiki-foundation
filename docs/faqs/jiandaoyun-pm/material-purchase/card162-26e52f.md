# 测算表、发起订单、供应商下单量

## 问题描述

业务同事反馈：业务同事，测算表请加一个关联限制。在发起订单的时候，选择测算表后，订单的供应商和物料编码、数量不能超出测算表中“供应商下单量”

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 采购、申购相关岗位
- **影响数据:** 测算表发起订单时供应商、物料编码、数量的控制；测算表数据代入订单的字段范围

## 原因分析

- 配置缺失：测算选申购，不能大于申购（是否可大取决于填写的下单百分比）；订单选测算，不能大于测算；只能通过选择测算物料明细带出测算量才能进行计算及控制；有测算的情况下订单可不再基于申购做限制，但申购单依然要选；测算量不能超申购量。

## 解决方案

1. 测算选申购，不能大于申购（是否可大取决于填写的下单百分比）
2. 订单选测算，不能大于测算
3. 只能通过选择测算物料明细带出测算量才能进行计算及控制
4. 有测算的情况下订单可不再基于申购做限制，但申购单依然要选

## 预防措施

- 当前订单若从申购明细带出，测算量为空则无法控制；可通过选择测算单后隐藏从申购选择、限定只能选测算明细实现；测算表流程走完后的「发起订单」按钮当前带过来的字段内容很简单，期望多带字段以减少重复操作。
- 在流程说明中明确相关规则，避免重复咨询。
