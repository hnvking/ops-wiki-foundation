# 月度申购汇总、村级申购、集采

## 问题描述

业务同事反馈：，月度申购汇总在关联村级申购的时候只能带出集采部分，非集采部分带不出是啥情况

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 采购、申购相关岗位
- **影响数据:** 相关单据与流程数据

## 原因分析

- 一个单据只能选一种，要么是集采，要么是非集采，选了就只能带出对应物资类型的数据。
