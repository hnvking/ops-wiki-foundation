# 订单单号、申购单明细编号、采购订单编码

## 问题描述

业务同事反馈：这个是订单单号吗黄经理

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 采购、申购相关岗位
- **影响数据:** 相关单据与流程数据

## 原因分析

- 流程规则不清：申购时可能还没有订单，因此申购单明细编号不是订单号；可通过申购单查看是否下订单，也可到指定位置找采购订单编码。

## 解决方案

1. 若找采购订单编码，到系统指定位置查看
2. 从申购单号进入也可查看是否已下订单

## 预防措施

- 不要把申购单明细编号当作订单单号。
- 在流程说明中明确相关规则，避免重复咨询。
