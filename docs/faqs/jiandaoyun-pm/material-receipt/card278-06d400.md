# 实际到货日期 实际调出日期 实际出库日期 字段配置

## 问题描述

业务同事反馈：老黄，这个直入直出单“实际到货日期”没见，我那天好像看着设置了

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 入库、对账相关岗位
- **影响数据:** 相关某模块数据

## 原因分析

- 配置缺失：调拨、出库、入库均需按同一标准带出实际日期（实际到货日期/实际调出日期/实际出库日期）。

## 解决方案

1. 调拨、出库、入库均需按同一标准带出实际日期（实际到货日期/实际调出日期/实际出库日期）。 调拨入库的实际调出日期已加并挪到上方，入库单已有实际到货日期字段，但关联带出实际到货日期、出库关联带出实际出库日期仍待完善，调拨、出库、入库统一按此标准
