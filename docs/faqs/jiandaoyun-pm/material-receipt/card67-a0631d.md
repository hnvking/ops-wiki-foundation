# 对账单选不到入库单、按项目分开对账

## 问题描述

业务同事反馈：黄经理，中财对账单导出来入库单的，是不是要把入库单号发给你

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 入库、对账相关岗位
- **影响数据:** 相关单据与流程数据

## 原因分析

- 用户操作：不同项目的入库单需分开单独做对账单。

## 解决方案

1. 做对账单时提供入库单编号核对，按项目分别发起对账单
