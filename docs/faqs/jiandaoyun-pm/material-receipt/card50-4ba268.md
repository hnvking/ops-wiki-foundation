# 入库单旧物资编码未从订单带出

## 问题描述

业务同事反馈：项目说的入库没有旧物资编码也是，档案里面是有旧物资编码的，入库单没有带出来

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 入库、对账相关岗位
- **影响数据:** 相关某模块数据

## 原因分析

- 配置缺失：入库单旧物料编码依赖从订单带出的字段配置，配置缺失则带不出。

## 解决方案

1. 入库单旧物料编码依赖从订单带出的字段配置，配置缺失则带不出。 原因为从订单带出旧物料编码此前未设置，现已补上配置
