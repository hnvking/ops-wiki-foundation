# 对账单 发起条件 直入直出 入库单 重复关联 流程状态 采购完成

## 问题描述

业务同事反馈：请教下，对账单之前的发起条件要求除了各种对应限制以外，有限制入库/直入直出流程走完才能发起吗？好像没有吧？ 第二个问题，对账单可以选入库单，也可以选直入直出单，那做直入直出单会生成入库单，那对账单选对应单据的要求是什么呢？是只能选直入直出还是要求必须选入库单呢？是否有考虑？

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 入库、对账相关岗位
- **影响数据:** 影响对账单发起条件、可关联单据范围、直入直出与入库单重复关联风险、订单审批状态写入位置。

## 原因分析

- 流程规则不清：采购完成就对账，跟出库无关；订单、合同、入库都要具备，零星采购除外；对账选入库，不直接选直入直出，避免直入直出自动生成入库单后重复关联；订单审批完成状态写入入库单；若仅限制流程走完，可用表单自身流程状态设置流程完成才能被选取，无需新增字段。

## 解决方案

1. 采购完成就对账，跟出库无关
2. 订单、合同、入库都要具备，零星采购除外
3. 对账选入库，不直接选直入直出，避免直入直出自动生成入库单后重复关联
4. 订单审批完成状态写入入库单

## 预防措施

- 直入直出会生成入库单，物资员若可随意选择直入直出或入库单，存在重复关联风险；物资发起对账时并不知道采购是否完成。
- 在流程说明中明确相关规则，避免重复咨询。
