# 订单修订、单价不反写、入库单

## 问题描述

业务同事反馈：订单编码CLDGDD-202608-000133，这个价格之前是错的152.6，今天供应链已经做的订单修订，流程也走完了，订单价格修订过来的。但是同步关联的入库单在做对账单的时候怎么变不过来吗？

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 入库、对账相关岗位
- **影响数据:** 影响已关联入库单的对账金额正确性；业务同事提出系统应把订单修订价格同步修正到关联入库单。

## 原因分析

- 数据异常：入库单单价在关联采购订单时带入；订单后续修订价格不会反写已关联入库单，对账单关联金额仍按入库单旧价。

## 解决方案

1. 入库单单价在关联采购订单时带入
2. 订单后续修订价格不会反写已关联入库单，对账单关联金额仍按入库单旧价。 业务同事查明该单不是预入库单，8月26日已有订单、9月15日做入库时按采购订单带过来的单价即错，属订单制作时价格做错
3. 订单修订后已关联的入库单价格不会同步变更，需通过扣罚单/手填费用或调差处理，问题转物资群跟进

## 预防措施

- 入库流程已走完时做不了附加费；入库单中看不到单价，当时难以及时发现价格错误。
- 在流程说明中明确相关规则，避免重复咨询。
