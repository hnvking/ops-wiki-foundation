# 订单引用不到、订单过期、订单有效期

## 问题描述

业务同事反馈：帮忙看一下 这张订单在做入库的时候引用不到 谢谢

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 入库、对账相关岗位
- **影响数据:** 相关单据与流程数据

## 原因分析

- 数据异常：订单过期会导致做入库时引用不到；订单有效期修改属业务问题，需联系订单组，IT不能随便改业务数据。

## 解决方案

1. 联系订单组处理订单有效期
2. 或按提问人提出的方式做预定单入库

## 预防措施

- IT不直接修改订单有效期等业务数据。
- 在流程说明中明确相关规则，避免重复咨询。
