# 提料单 订单量 入库量 申购剩余量 无订单入库 一物一码

## 问题描述

业务同事反馈：2026- :36 : 陈总，我们订单和提料单的数量关系是啥 ; … 现在是提料单总量不能超订单总量吗 ; 还是提料单总量不能超订单未入库量

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 入库、对账相关岗位
- **影响数据:** 历史已存在超量的单据需要处理；缺项目档案采购管理角色人员导致供应链重新下正式订单未与无订单入库关联。

## 原因分析

- 配置缺失：原订单量未限制提料量，导致无订单余量仍可入库；一物一码模式下必须先下订单才能做提料-送货-入库，因此不会有无订单入库；已开启入库量不允许超申购剩余量。

## 解决方案

1. 项目档案设置采购管理角色等角色为必填
