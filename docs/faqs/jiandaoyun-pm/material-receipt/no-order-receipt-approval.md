# 无订单入库的审核方式

## 问题描述

业务同事咨询：无订单入库应当按订单审核，还是按入库审核？

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 采购执行人、入库对接人
- **影响数据:** 无订单入库的审批节点设置与参与角色

## 原因分析

- 流程规则不清：无订单入库既涉及入库动作，又会派生采购订单，审核口径不明确。

## 解决方案

1. 无订单入库按**入库**审核，审核通过后生成订单。
2. 审批节点直接给入库对接人，不需要采购执行人审批。
3. 调整审批流配置后，验证审批走向与订单生成结果。

## 预防措施

- 在无订单入库的流程说明中明确审核口径与参与角色，避免重复咨询。
