# 订单入库带不出明细、订单已完成全部入库且被引用

## 问题描述

业务同事反馈：领导 清新项目CLDGDD-202610-000023这个订单入库带不出明细可以解决一下吗？

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 入库、对账相关岗位
- **影响数据:** 相关单据与流程数据

## 原因分析

- 流程规则不清：订单已完成全部入库或被引用过后，不能再带出材料明细做入库/直入直出。

## 解决方案

1. 订单已完成全部入库或被引用过后，不能再带出材料明细做入库/直入直出。 核实该订单对应物流显示已完成全部入库故选不到材料，且该订单已被引用过

## 预防措施

- 关联订单前先确认订单是否已全部入库或已被引用。
- 在流程说明中明确相关规则，避免重复咨询。
