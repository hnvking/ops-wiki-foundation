# 预入库 是否有订单 申购明细 数量扣减 已下单量

## 问题描述

业务同事反馈：项目发起预入库流程的时候，是否有订单选了否，是一定要选申购带出材料明细和数量的对吧，这个带出来的数量需要减去已经发起了订单的数量。

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 入库、对账相关岗位
- **影响数据:** 影响无订单预入库数量计算及申购汇总明细记录。

## 原因分析

- 配置缺失：是否有订单选否时，需要选择申购带出材料明细和数量，带出数量应减去已发起订单数量；例如申购100、订单发起99，则无订单入库数量只能为1。当前申购汇总/材料明细汇总未记录每个物料发起过多少采购订单。

## 解决方案

1. 是否有订单选否时，需要选择申购带出材料明细和数量，带出数量应减去已发起订单数量
2. 例如申购100、订单发起99，则无订单入库数量只能为1。当前申购汇总/材料明细汇总未记录每个物料发起过多少采购订单。 确认无订单预入库数量规则为申购数量减去已发起订单数量，但申购汇总、材料明细汇总中未记录每个物料已发起多少采购订单

## 预防措施

- 系统当前缺少每个物料已发起订单数量的记录，需避免无订单入库数量超发。
- 在流程说明中明确相关规则，避免重复咨询。
