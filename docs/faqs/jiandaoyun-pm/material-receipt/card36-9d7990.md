# 无订单入库、自动生成订单、选合同无法选明细

## 问题描述

业务同事反馈：[图片]请问为什么无订单入库后自动生成的订单，选完合同后还是无法选择明细呢？

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 入库、对账相关岗位
- **影响数据:** 影响无订单入库自动生成订单的明细带出及在途异常数据处理。

## 原因分析

- 配置缺失：正式入库和预入库都必须等申购流程正常结束才能做；系统已限制只能选流程正常结束的申购单。

## 解决方案

1. 确认关联申购流程正常结束后再做入库
2. 异常数据由发起人完善资料重新上流程或自行撤销申购

## 预防措施

- IT 运维组指出申购流程被否决却强行做完入库单并生成在途采购订单时，发起人没有后续单据操作权限；业务同事对该数据成因存在不同说法（称做预入库时未选申购、另有走完的申购），对话未收敛。
- 在流程说明中明确相关规则，避免重复咨询。
