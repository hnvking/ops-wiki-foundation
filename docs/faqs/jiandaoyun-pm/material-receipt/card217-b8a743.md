# 入库单编号误填直入直出编号导致订单字段找不到

## 问题描述

业务同事反馈：这个是什么问题

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 入库、对账相关岗位
- **影响数据:** 相关单据与流程数据

## 原因分析

- 用户操作：入库单编号字段填写为直入直出编号时无法匹配对应订单字段数据；建议改为先单选再带出其中一个。

## 解决方案

1. 入库单编号字段填写为直入直出编号时无法匹配对应订单字段数据
2. 建议改为先单选再带出其中一个 IT 运维组解释为用户选择了入库单，但实际填写的入库单编号字段内容为直入直出编号，导致找不到对应订单字段数据，并提出改为先单选再带出之一的设计以规避重复发生

- 在流程说明中明确相关规则，避免重复咨询。
