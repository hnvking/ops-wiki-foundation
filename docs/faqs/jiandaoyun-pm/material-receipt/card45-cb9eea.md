# 订单价格正确、直入直出单价错误、重选订单未重选物料

## 问题描述

业务同事反馈：采购订单价格没有错，直入直出单关联的订单也没有错，为什么自动带出来的单价是错的？

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 入库、对账相关岗位
- **影响数据:** 影响直入直出单自动带出的单价正确性。

## 原因分析

- 用户操作：单价随所选订单下的物料带出；重选订单但未重选物料会保留旧单价。入库单选错订单需强制关闭重新选，直入直出暂未做该限制。

## 解决方案

1. 单价随所选订单下的物料带出
2. 重选订单但未重选物料会保留旧单价。入库单选错订单需强制关闭重新选，直入直出暂未做该限制。 业务同事推断是制单时先选了其他订单带出物资、发现选错后重选订单但未重选物料导致
3. 入库单已改为选了项目/订单就隐藏，选错需强制关闭订单重新选，但直入直出尚未这样设计

## 预防措施

- 直入直出单尚未实现选错订单强制关闭重选的控制，需人工核对单价。
- 在流程说明中明确相关规则，避免重复咨询。
