# 直入直出 入库单 订单编码 采购订单明细编号 表单视图

## 问题描述

业务同事反馈：直入直出生成的入库单是没有订单编码的

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 入库、对账相关岗位
- **影响数据:** 影响直入直出生成入库单中的订单编码展示。

## 原因分析

- 配置缺失：直入直出生成的入库单只有采购订单明细编号，未设置采购订单编号；流程中有订单编码，但表单视图未带出。

## 解决方案

1. 直入直出生成的入库单只有采购订单明细编号，未设置采购订单编号
2. 流程中有订单编码，但表单视图未带出。 IT 运维组说明直入直出只有采购订单的明细编号，之前没有设置采购订单编号，流程里面有但表单视图带不出来

## 预防措施

- 在流程说明中明确相关规则，避免重复咨询。
