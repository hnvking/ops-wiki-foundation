# 提料单选择劳务合同取消必填、后续审批节点可完善

## 问题描述

业务同事反馈：确实，他写在另外一个地方，刚没看到，提料单自动生成直入直出单也只是发起节点，后面的审批节点是可以完善相关字段的，所以这个提料单的选择劳务合同字段是可以取消必填的。

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 入库、对账相关岗位
- **影响数据:** 提料单及自动生成的直入直出单

## 原因分析

- 配置缺失：提料单自动生成直入直出单只作用于发起节点，后续审批节点可补充字段，故选择劳务合同不必在提料单强制必填。

## 解决方案

1. 提料单自动生成直入直出单只作用于发起节点，后续审批节点可补充字段，故选择劳务合同不必在提料单强制必填 确认提料单生成直入直出单仅在发起节点自动生成，后续审批节点可完善字段，因此提料单选择劳务合同字段可取消必填
