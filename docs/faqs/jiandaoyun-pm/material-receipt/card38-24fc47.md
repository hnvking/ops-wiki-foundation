# 预入库单、订单反推、订单流程未走完

## 问题描述

业务同事反馈：黄经理，这份预入库单，供应链那边下的订单反推不过来

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 入库、对账相关岗位
- **影响数据:** 影响丰顺项目预入库单与订单的对应关系。

## 原因分析

- 流程规则不清：订单流程走完才能反写入库单；预入库单与供应链手工订单不能并存。

## 解决方案

1. 二选一：使用供应链订单号则取消预入库单重新做
2. 保留预入库单则催促其自动生成的订单尽快审批完成

## 预防措施

- 不能又有预入库单生成的订单，又有供应链手工下的订单。
- 在流程说明中明确相关规则，避免重复咨询。
