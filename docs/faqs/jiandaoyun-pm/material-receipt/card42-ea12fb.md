# 物资编码错误、无订单入库、村申购

## 问题描述

业务同事反馈：还有个问题，现在无订单入库的清单因为没有用申购做订单的环节，我们没法确认申购材料编码是不是合同签订的，现在发现有一批编码错误的，怎么处理啊业务同事 业务同事

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 入库、对账相关岗位
- **影响数据:** 影响一批编码错误的无订单入库清单及供应链审批。

## 原因分析

- 流程规则不清：物资编码错误需从源头村级申购改起；申购/合同清单中仍有该物料编码时只需改入库明细；线下审批资料应为供应链同意供货凭证。

## 解决方案

1. 物资编码错误需从源头村级申购改起
2. 申购/合同清单中仍有该物料编码时只需改入库明细
3. 线下审批资料应为供应链同意供货凭证。 IT 运维组答复入库已提交到供应链审批时估计很难改，要追溯到源头村申购去改
4. 若申购或合同清单里还有那个物料编码，则只需改入库明细

## 预防措施

- 无订单入库缺少申购做订单环节，无法校验申购材料编码是否为合同签订编码。
- 在流程说明中明确相关规则，避免重复咨询。
