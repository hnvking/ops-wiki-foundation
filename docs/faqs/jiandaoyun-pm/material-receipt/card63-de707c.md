# 对账单不可选直入直出、只选入库单、防重复对账

## 问题描述

业务同事反馈：旭岚的对账单为什么选择不了直入直出？求解决

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 入库、对账相关岗位
- **影响数据:** 所有物资同事做对账单

## 原因分析

- 流程规则不清：对账单只能选流程完成且订单已完成的入库单；直入直出流程走完会自动生成入库单，只能选入库单做对账，避免直入直出单与入库单重复做对账。

## 解决方案

1. 直入直出流程走完后找到对应自动生成的入库单，用该入库单做对账单

## 预防措施

- 直入直出单与入库单以前两边都能选会重复做对账；现在只有一条路，只选入库单。
- 在流程说明中明确相关规则，避免重复咨询。
