# 测算表、已下单未发货、订单减入库

## 问题描述

业务同事反馈：这2个公式还没改，那之前肯定也不对呀，也没关注过？ 那现在要改成订单-入库是吗

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 入库、对账相关岗位
- **影响数据:** 测算表已下单未发货及金额字段统计口径

## 原因分析

- 配置缺失：「已下单未发货」= 订单 - 入库；金额字段取值为所有订单明细中该供应商该物料的合计。

## 解决方案

1. 「已下单未发货」= 订单 - 入库
2. 金额字段取值为所有订单明细中该供应商该物料的合计。 确认「已下单未发货」公式取值应为订单减入库，原公式未改导致统计不对，需按此口径修正

## 预防措施

- 字段公式调整前历史数据均按错误口径计算，需评估历史数据影响。
- 在流程说明中明确相关规则，避免重复咨询。
