# 产成品退库 红字产成品入库 生产任务单 不关联

## 问题描述

业务同事反馈：”产成品入库“按正常生产任务单，入完库后；产成品后面要退货，在哪里操作？

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 入库、对账相关岗位
- **影响数据:** 生产订单合格入库数量不会因红字产成品入库还原到未入状态。

## 原因分析

- 产成品入库表体的产成品入库单字段为文本格式，不能关联生产任务；生产属企业内部行为，完工前质量问题直接报废/返工，已入库可做返修业务，标准产品不支持红字生产订单。

## 解决方案

1. 在【供应链-库存管理-入库业务-产成品入库】新增产成品入库单，表头表体按原单填写，数量填负数，保存审核完成退库

## 预防措施

- 无法通过参照原生产任务单实现退库并还原合格入库数量；生产订单不会还原到未入状态。
- 在流程说明中明确相关规则，避免重复咨询。
