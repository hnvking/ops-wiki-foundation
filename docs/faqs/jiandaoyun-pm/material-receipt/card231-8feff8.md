# 无订单直入直出单大批审批将生成大量订单需先与供应链专题确认

## 问题描述

业务同事反馈：[图片]黄经理，我现在一直在审批直入直出单，有几十上百条。都是无订单的哦，后面也应该是会生成几十上百条订单吧。我和你反馈下哈，到时候供应链就会有很多订单哦

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 入库、对账相关岗位
- **影响数据:** 供应链侧会生成几十上百条订单

## 原因分析

- 流程规则不清：大量无订单直入直出单会后续生成大量采购订单，大面积启用前需先与供应链确认并开专题会议。

## 解决方案

1. 大量无订单直入直出单会后续生成大量采购订单，大面积启用前需先与供应链确认并开专题会议 IT 运维组答复订单多要先跟供应链确认，建议开专题会议后再大面积上

## 预防措施

- 在流程说明中明确相关规则，避免重复咨询。
