# 订单看板 入库状态 材料订单明细 台账显示

## 问题描述

业务同事反馈：订单看板具体是指那个功能，仪表盘吗？

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 入库、对账相关岗位
- **影响数据:** 影响订单看板/台账中入库状态信息的展示位置。

## 原因分析

- 配置缺失：订单入库状态字段在材料订单明细表中并已带到材料订单；材料订单台账不显示该字段，只显示标记点。

## 解决方案

1. 订单入库状态字段在材料订单明细表中并已带到材料订单
2. 材料订单台账不显示该字段，只显示标记点。 订单看板是用于查看订单入库状态，相关入库状态字段已带到材料订单明细中，但材料订单台账上不显示，只显示标记点

## 预防措施

- 在订单台账看不到入库状态明细时，需到材料订单明细查看。
- 在流程说明中明确相关规则，避免重复咨询。
