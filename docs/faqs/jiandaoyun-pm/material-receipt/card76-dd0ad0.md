# 对账单供应商不一致、核对字段

## 问题描述

业务同事反馈：对账单前面选的什么，你截图我看看

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 入库、对账相关岗位
- **影响数据:** 相关单据与流程数据

## 原因分析

- 用户操作：对账单关联时需核对入库单供应商与订单接收供应商一致。

## 解决方案

1. 做对账单前核对入库单供应商与订单供应商
