# 对账单选入库单、直入直出自动生成入库单

## 问题描述

业务同事反馈：对账单流程 选择入库单那一栏添加不到直入直出单噢 入库类型只显示入库单 选不了直入直出单

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 入库、对账相关岗位
- **影响数据:** 相关单据与流程数据

## 原因分析

- 流程规则不清：直入直出单流程走完会自动生成入库单；对账单只选入库单，避免直入直出单与入库单重复做对账单。

## 解决方案

1. 按设置可筛选出入库单
2. 做对账单时关联对应的入库单

## 预防措施

- 在流程说明中明确相关规则，避免重复咨询。
