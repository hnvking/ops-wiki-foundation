# 测算表、年度集采到货金额、已下单金额

## 问题描述

业务同事反馈：年度集采到货金额(不含本次)(万元)==8.4.2入库单的 对应合同编号的 入库含税金额 ； 2025年度集采已下单金额（万元）==7.5.合同明细的 对应合同编号的 普通合同含税金额； 年度集采到货金额（万元）== 本表单的：F-最终确定合价+年度集采到货金额(不含本次)(文本) 年度集采到货金额(不含本次)(文本)==材料入库明细，按供应商名称，含税单价…

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 入库、对账相关岗位
- **影响数据:** 测算表年度集采金额相关字段统计口径

## 原因分析

- 配置缺失：年度集采到货金额(不含本次)取8.4.2入库单中对应合同编号的入库含税金额；2025年度集采已下单金额取7.5.合同明细中对应合同编号的普通合同含税金额；年度集采到货金额=本表单F-最终确定合价+年度集采到货金额(不含本次)(文本)；按供应商名称对含税单价求和不能作为金额。

## 解决方案

1. 年度集采到货金额(不含本次)取8.4.2入库单中对应合同编号的入库含税金额
2. 2025年度集采已下单金额取7.5.合同明细中对应合同编号的普通合同含税金额
3. 年度集采到货金额=本表单F-最终确定合价+年度集采到货金额(不含本次)(文本)
4. 按供应商名称对含税单价求和不能作为金额。 梳理年度集采金额各字段取值口径，指出「年度集采到货金额(不含本次)(文本)」误将含税单价求和当作金额，提出改为求和普通合同含税金额，并提示入库单与合同可能存在多对一关系需确认

## 预防措施

- 入库单对应的合同来源是订单，可能只会选其中一个编码，存在多对一关系，用入库单取数需确认口径；金额字段不得求和单价。
- 在流程说明中明确相关规则，避免重复咨询。
