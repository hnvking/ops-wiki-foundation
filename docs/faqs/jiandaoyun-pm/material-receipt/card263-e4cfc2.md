# 产成品入库 结转成本 料工费未分开 存货核算

## 问题描述

业务同事反馈：王老师：我们产成品入库单结转成本为什么不把材料、人工、制造分开结转，而是把人工、制费的金额加到材料里面去结转呢？

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 入库、对账相关岗位
- **影响数据:** 相关某模块数据

## 原因分析

- 配置缺失：存货核算生成凭证时不区分材料、人工、制造费用，人工与制费金额并入材料结转。

## 解决方案

1. 存货核算生成凭证时不区分材料、人工、制造费用，人工与制费金额并入材料结转。 原因是该凭证由存货核算的产成品入库单生成，存货核算本身不区分料工费，后续需向实施同事了解背景
