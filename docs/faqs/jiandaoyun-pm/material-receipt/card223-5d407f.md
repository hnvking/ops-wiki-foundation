# 入库量大于订单量且无其他关联入库记录的处理与单据重新提交

## 问题描述

业务同事反馈：用户：[图片]入库时，入库量大于订单量，这个订单没有关联过其他入库，麻烦帮忙处理一下，采购订单号：[单据编号] 答复：通过订单查具体超量物料并追踪物料入库情况发现之前有2条物料入库数据。 用户：这个日期的有个单重新提交了，那就没有问题了，谢谢

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 入库、对账相关岗位
- **影响数据:** 相关单据与流程数据

## 原因分析

- 数据异常：入库量大于剩余订单量时系统限制提交；需通过订单编号查具体超量物料、追踪物料入库历史、检查是否存在重新提交单据并确认其是否已正确关联或处理。

## 解决方案

1. 1. 通过订单编号查询具体超量物料
2. 2. 追踪该物料的入库历史数据
3. 3. 检查是否存在单据重新提交导致的历史入库记录被覆盖或合并
4. 4. 若发现重新提交单据，确认其是否已正确关联或处理以消除差异

## 预防措施

- 在流程说明中明确相关规则，避免重复咨询。
