# 无订单入库税额异常、单价由供应链修改

## 问题描述

业务同事反馈：我昨天做的无订单入库 无税额价格正常 入库税额特别多 是不是哪里有问题

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 入库、对账相关岗位
- **影响数据:** 相关单据与流程数据

## 原因分析

- 数据异常：无订单入库单价异常由供应链在采购执行人环节修改，数量无误不影响流程通过。

## 解决方案

1. 无订单入库单价异常由供应链在采购执行人环节修改，数量无误不影响流程通过。 确认单价确实有问题，流程数量无误可先过，单价由供应链到采购执行人处修改

## 预防措施

- 单价异常需供应链侧修正，物资端不必卡流程。
- 在流程说明中明确相关规则，避免重复咨询。
