# 申购汇总、按编码合并、镇信息

## 问题描述

业务同事反馈：业务同事 因地材物资名称、规格中取消镇信息，所以申购汇总审批要取消按编码合并，保留原申购单的镇信息，不然我们无法做订单。请问是否可以开发

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 入库、对账相关岗位
- **影响数据:** 申购汇总、测算表、订单；影响下单、到货、对账等单据关联及审批环节

## 原因分析

- 流程规则不清：物资先做按村的月度申购单，再做按项目汇总物料信息的月度申购汇总；原申购汇总按物料编码汇总各村明细；地材物资名称、规格中取消镇信息后需保留原申购单的镇信息才能做订单；按镇分别提申购汇总可让下单、到货、对账等对应关系清晰。

## 解决方案

1. 物资先做按村的月度申购单，再做按项目汇总物料信息的月度申购汇总
2. 原申购汇总按物料编码汇总各村明细
3. 地材物资名称、规格中取消镇信息后需保留原申购单的镇信息才能做订单
4. 按镇分别提申购汇总可让下单、到货、对账等对应关系清晰。 明确当前按物料编码汇总各村明细会因镇信息取消影响做订单，建议项目上按镇分别提申购汇总以保持对应关系清晰，并确认修改涉及申购汇总、测算表及订单，具体需当面沟通

## 预防措施

- 核心诉求是做好单据数据关联性、减少人为因素影响，可借此减少关联单据审批环节、加快审批速度；浦念方面尚未理解村编码、镇编码与合并关系，建议当面沟通后再开发。
- 在流程说明中明确相关规则，避免重复咨询。
