# 直入直出出库单未自动通过审批、删除重建

## 问题描述

业务同事反馈：这条直入直出的出库单为什么没有自动通过审批。

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 入库、对账相关岗位
- **影响数据:** 相关单据与流程数据

## 原因分析

- 系统缺陷：删除原出库单PMCLCKD-202610-00000266并新生成PMCLCKD-202610-[编号]，制单人手动审批后已完成，后续无需再手动。

## 解决方案

1. 删除异常出库单、重新生成新出库单，由制单人手动审批一次

## 预防措施

- 需区分直入直出单与系统生成的出库单，待办中的是出库单。
