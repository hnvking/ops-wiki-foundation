# 入库单 关联订单按钮隐藏 材料明细清空 是否有订单

## 问题描述

业务同事反馈：入库单关联订单的按钮没了

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 入库、对账相关岗位
- **影响数据:** 影响入库单订单关联按钮、历史数据默认值及台账字段展示宽度。

## 原因分析

- 配置缺失：入库单选了订单后隐藏订单按钮，避免先选订单再选材料后又重新选订单，导致之前材料对应不上之前订单；订单与材料选完后变更订单，应清空原订单带出的入库材料明细；台账字段改为是否有订单，取值为是/否。

## 解决方案

1. 入库单选了订单后隐藏订单按钮，避免先选订单再选材料后又重新选订单，导致之前材料对应不上之前订单
2. 订单与材料选完后变更订单，应清空原订单带出的入库材料明细
3. 台账字段改为是否有订单，取值为是/否。 物资要求选了订单后隐藏订单按钮，防止重新选订单导致已选材料与原订单不匹配
4. 历史数据默认需改为订单入库，并计划将字段改为是否有订单

## 预防措施

- 历史数据当前默认空值，需统一改为订单入库；变更订单时应清空原订单带出的入库材料明细。
- 在流程说明中明确相关规则，避免重复咨询。
