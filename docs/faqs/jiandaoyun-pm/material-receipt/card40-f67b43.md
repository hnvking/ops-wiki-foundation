# 有订单入库、无订单入库、临时方案

## 问题描述

业务同事反馈：现在有订单了，可不可以改成关联订单入库？

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 入库、对账相关岗位
- **影响数据:** 影响已有订单情况下的入库方式选择。

## 原因分析

- 用户操作：有订单时优先走有订单入库；无订单入库仅用于确实没有订单又着急入库的临时场景。

## 解决方案

1. 已有订单时改选有订单入库
2. 若之前关联过预入库，需删除遗留的申购单再试

## 预防措施

- 直接选有订单但之前的申购单未删除会持续报错；原被预入库关联的订单量需释放。
- 在流程说明中明确相关规则，避免重复咨询。
