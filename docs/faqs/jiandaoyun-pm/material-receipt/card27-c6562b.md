# 预出入库、对账单、合同编号

## 问题描述

业务同事反馈：这张预出入库单也带不出来 有填写合同编号的预出库单可以在对账单流程里带出来 没填写或无合同的预出入库单对账单流程都带不出来

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 入库、对账相关岗位
- **影响数据:** 影响无合同预出入库单参与供应商对账。

## 原因分析

- 配置缺失：对账单流程按合同编号匹配入库单，有合同且填写合同编号才能带出；无合同或合同空白、只填供应商名称带不出。

## 解决方案

1. 对账单流程按合同编号匹配入库单，有合同且填写合同编号才能带出
2. 无合同或合同空白、只填供应商名称带不出。 业务同事进一步确认有合同且选了合同编号的入库单可在对账流程带出，填无合同、合同处空白或只选供应商名称的均带不出，IT 运维组说明入库单选了对应合同才会带过来对应数据

## 预防措施

- 供应商合同编号多，选错也会导致关联不到。
- 在流程说明中明确相关规则，避免重复咨询。
