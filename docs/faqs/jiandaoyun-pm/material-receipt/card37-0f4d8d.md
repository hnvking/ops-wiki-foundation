# 匿名用户、合同带错、单价不对

## 问题描述

业务同事反馈：[图片]无订单入库匿名用户是谁发起的，带的合同不对，单价也不对，我改这个合同单价也不对，是不是要发起人换合同关联才行

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 入库、对账相关岗位
- **影响数据:** 影响自动生成订单的合同与单价正确性及发起人归属。

## 原因分析

- 配置缺失：无订单入库只是没有订单，合同肯定有；需选择对应合同才能后续生成订单及带出单价；自动生成订单的发起人改为入库单表单发起人。

## 解决方案

1. 由下单人节点选择是否有合同并选择对应合同
2. 自动生成订单以入库单发起人为发起人

## 预防措施

- 手动触发的订单可能带错发起人/合同；黄小慧问合同选错后能否修改，对话未明确答复。
- 在流程说明中明确相关规则，避免重复咨询。
