# 地材对账 单价 统一编码 进场总金额 总数量 不同镇价格 单列

## 问题描述

业务同事反馈：对账流程有个问题，现在地材的对账单价是用统一编码的进场总金额除以总数量算的单价，这个是不对的。我们不同的镇有不同的价格，这个要单列

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 入库、对账相关岗位
- **影响数据:** 影响地材对账单单价计算与对账结果。

## 原因分析

- 配置缺失：地材对账单价不能用统一编码下进场总金额除以总数量得到；不同镇有不同价格，应按镇单列。

## 解决方案

1. 地材对账单价不能用统一编码下进场总金额除以总数量得到
2. 不同镇有不同价格，应按镇单列。 确认地材对账单价按统一编码的进场总金额除以总数量计算不正确，不同镇价格不同需要单列

## 预防措施

- 按统一编码汇总均价会掩盖不同镇价格差异。
- 在流程说明中明确相关规则，避免重复咨询。
