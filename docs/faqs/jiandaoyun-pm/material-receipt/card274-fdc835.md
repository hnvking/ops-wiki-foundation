# 附加费 单价带出 订单明细 物料档案 地材

## 问题描述

业务同事反馈：你选择订单明细，订单里面有单价就会带出来，如果选择物料档案就不会

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 入库、对账相关岗位
- **影响数据:** 所有地材供应商附加费已维护但物资入库仍反馈价格需手填。

## 原因分析

- 配置缺失：单价由订单明细带出，物料档案不带单价；附加费是物资入库时按实际超时/超距手填数量，订单明细不体现附加费。

## 解决方案

1. 单价由订单明细带出，物料档案不带单价
2. 附加费是物资入库时按实际超时/超距手填数量，订单明细不体现附加费。 单价带出规则说明：选择订单明细可带出订单中的单价，选择物料档案则不会带出
3. 附加费因订单明细不含附加费（仅主材数量），虽已维护地材供应商附加费价格，物资入库仍需手填，未达预期，需排查原因
