# 调整自动生成订单字段填充、隐藏与手动补充规则

## 问题描述

业务同事反馈：有些必填的可以直接设置好，像城市 车型这些。不需要填的就给人家隐藏掉，像成本所属月，是否有合同什么的

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 入库、对账相关岗位
- **影响数据:** 自动生成的采购订单、采购执行人/入库对账付款负责人审批节点、PM 与 NC 同步链条、后续对账单；字段自动填充缺失会导致订单信息不完整、审批补录或同步失败。

## 原因分析

- 无订单入库/直入直出走完后会自动生成采购订单，触发数据来自材料入库单。订单名称、订单类型、下单城市、车型、是否合同、预计到货时间、送货地址等字段配置为自动填充；测算表隐藏；付款方式触发数据不带出，需选合同后手动补充或自动带出；单价、金额、税率依赖入库单对应值，相关节点需完善合同及单价。

## 解决方案

1. 无订单入库/直入直出走完后会自动生成采购订单，触发数据来自材料入库单。订单名称、订单类型、下单城市、车型、是否合同、预计到货时间、送货地址等字段配置为自动填充
2. 测算表隐藏
3. 付款方式触发数据不带出，需选合同后手动补充或自动带出
4. 单价、金额、税率依赖入库单对应值，相关节点需完善合同及单价。 调整自动生成订单字段填充、隐藏与手动补充规则
