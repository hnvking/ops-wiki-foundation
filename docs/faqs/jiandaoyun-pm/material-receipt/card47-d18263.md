# 单价类型没配置、无法提交、订单明细空白

## 问题描述

业务同事反馈：[单据编号]000399订单明细的单价类型没配置，无法提交

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 入库、对账相关岗位
- **影响数据:** 影响该采购订单提交。

## 原因分析

- 数据异常：订单明细由入库单带入；入库单未选时订单明细空白，无法选择单价类型也无法提交。

## 解决方案

1. 订单明细由入库单带入
2. 入库单未选时订单明细空白，无法选择单价类型也无法提交。 IT 运维组建议设置单价类型后再提交看是否同步过去
3. IT 运维组反馈与上面选择无关，真实原因是入库单没选导致带过来的订单明细为空白、无法选择

## 预防措施

- 仅设置单价类型不能解决，需先处理入库单关联。
- 在流程说明中明确相关规则，避免重复咨询。
