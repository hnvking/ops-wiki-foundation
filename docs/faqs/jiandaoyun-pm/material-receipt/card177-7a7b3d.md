# 水泥井入库、13.5米车型、单价不跳转

## 问题描述

业务同事反馈：水泥井重新入库选了13.5米车辆类型，单价还是没跳转

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 入库、对账相关岗位
- **影响数据:** 水泥井等非管材类入库时按车型调整单价的诉求、后续对账单价调差

## 原因分析

- 配置缺失：直入直出单的物料单价与车型无关，选择任何车型都不会变；只有公司集采的管材类才会根据车辆类型变更单价；系统原设计仅按三个选项带出单价，不会按车型自动变单价；入库按送货单实际送货车型选择，车型单价根据合同变化。

## 解决方案

1. 直入直出单的物料单价与车型无关，选择任何车型都不会变
2. 只有公司集采的管材类才会根据车辆类型变更单价
3. 系统原设计仅按三个选项带出单价，不会按车型自动变单价
4. 入库按送货单实际送货车型选择，车型单价根据合同变化。 确认直入直出单物料单价跟车型无关，只有公司集采的管材类才会根据车辆类型变更单价

## 预防措施

- 订单按9.6米单价做但实际送货为13.5米车型时，入库单价不会自动重算；未解决前可先按车型单价调差提交对账单流程。
- 在流程说明中明确相关规则，避免重复咨询。
