# 采购订单流程应转交对应下单人并在出入库单据加人

## 问题描述

业务同事反馈：黄经理，这2个订单，不是业务同事负责的，要转给黄小慧 2026- :59 业务同事: [图片] ; 2026- :06 业务同事: 这些要转交到对应的下单人 ; 2026- :09 业务同事: 不是转交给我 ; 2026- :22 业务同事: 这两条流程你那边能不能撤回？ ; 2026- :29 业务同事: 惠东是小慧

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 入库、对账相关岗位
- **影响数据:** 相关单据与流程数据

## 原因分析

- 流程规则不清：流程应转交给对应下单人；出入库单据加上对应人员后，后续新流程会流转到对应人员。

## 解决方案

1. 流程应转交给对应下单人
2. 出入库单据加上对应人员后，后续新流程会流转到对应人员 IT 运维组答复出入库单据已加上对应人员，后续新流程就会到他们

## 预防措施

- 在流程说明中明确相关规则，避免重复咨询。
