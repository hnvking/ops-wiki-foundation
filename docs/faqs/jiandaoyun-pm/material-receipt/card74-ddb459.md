# 对账关联不出数据、采购订单未走完

## 问题描述

业务同事反馈：为啥这些流程都走完那么久了 对账还是关联不出数据

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 入库、对账相关岗位
- **影响数据:** 相关单据与流程数据

## 原因分析

- 流程规则不清：即便其他流程走完，采购订单未走完仍无法关联对账数据。

## 解决方案

1. 即便其他流程走完，采购订单未走完仍无法关联对账数据。 核实为采购订单没走完，已协助催促
2. 后续IT 运维组反馈走完后已能入有订单入库

## 预防措施

- 排查对账关联不到数据时需先确认采购订单流程是否结束。
- 在流程说明中明确相关规则，避免重复咨询。
