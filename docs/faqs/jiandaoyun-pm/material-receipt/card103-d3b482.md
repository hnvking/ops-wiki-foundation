# 入库反写 采购订单 采购明细单 供应商变更

## 问题描述

业务同事反馈：入库后不是要反写采购订单吗，采购订单还牵扯采购明细单，主要是沟通采购单的细节

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 入库、对账相关岗位
- **影响数据:** 涉及采购订单、采购明细单及供应商变更方案沟通。

## 原因分析

- 流程规则不清：本次需求焦点为采购订单供应商变更可行性，不是入库后反写采购订单。

## 解决方案

1. 本次需求焦点为采购订单供应商变更可行性，不是入库后反写采购订单。 IT 运维组明确当前讨论不是入库后反写采购订单，而是要确定采购订单能否做供应商变更

## 预防措施

- 讨论采购单细节时需区分入库反写订单与供应商变更两类问题。
- 在流程说明中明确相关规则，避免重复咨询。
