# 无订单入库、供应商对账、订单审批

## 问题描述

业务同事反馈：无订单入库流程未审批结束，给供应商对账的时候是不是选不了这条数据？

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 入库、对账相关岗位
- **影响数据:** 影响供应商对账流程发起条件，预入库未审批结束或订单未完成均无法对账。

## 原因分析

- 流程规则不清：单纯业务上必须有了订单和入库才跟供应商对账；入库数据需匹配订单信息才能计入对账单；对账单只能选择流程完成且订单已完成的入库单。

## 解决方案

1. 等待无订单入库流程及自动生成的采购订单审批完成，再用订单已完成的入库单发起对账

## 预防措施

- 订单未通过时对账没有意义；后期会增设限制条件。
- 在流程说明中明确相关规则，避免重复咨询。
