# 含税单价、不含税单价、入库金额

## 问题描述

业务同事反馈：这张预入库单，含税单价和不含税单价一样，结算计算出来的入库含税金额 入库无税金额又变成不一样

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 入库、对账相关岗位
- **影响数据:** 影响预入库单结算金额计算。

## 原因分析

- 配置缺失：金额不应从申购单带出，申购带出金额与实际金额不符，故取消该取值。

## 解决方案

1. 金额不应从申购单带出，申购带出金额与实际金额不符，故取消该取值。 IT 运维组答复已处理，原因是之前金额从申购里面带出来、与实际金额不符，已取消
