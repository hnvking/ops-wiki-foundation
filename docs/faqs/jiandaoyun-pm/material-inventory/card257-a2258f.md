# 销售出货结束 执行查询不到 手工做单 未做出库

## 问题描述

业务同事反馈：请问一下这个销售出货节点已经结束了，但是在NC销售出库执行查询上找不到的

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 物资、出库相关岗位
- **影响数据:** 相关单据与流程数据

## 原因分析

- 用户操作：销售出库为手工做单时，发货单未生成销售出库单，执行查询表只能查到已生成的销售出库单据；[单据编号]002销售订单对应的4张销售出库单在执行查询表可查到。

## 解决方案

1. 由仓库参照发货单做销售出库
