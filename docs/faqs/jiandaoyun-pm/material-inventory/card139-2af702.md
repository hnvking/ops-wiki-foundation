# 工作面分配 流程节点锁死 重新审核 审批意见 直达审批

## 问题描述

业务同事反馈：这个工作面分配的流程节点，这里好像被锁死了，只要有人有意见，所有人都要重新审核，

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 物资、出库相关岗位
- **影响数据:** 影响工作面分配流程退回/重审节点规则。

## 原因分析

- 配置缺失：当前流程只要有人有意见，所有人都要重新审核；期望可选择审批意见、对方修改后直接回到该审批人审批。

## 解决方案

1. 当前流程只要有人有意见，所有人都要重新审核
2. 期望可选择审批意见、对方修改后直接回到该审批人审批。 IT 运维组指出工作面分配流程锁死，有人有意见时所有人都要重新审核，期望自己审批意见后由对方修改再直达自己审批，但本会话未见配置结论

## 预防措施

- 在流程说明中明确相关规则，避免重复咨询。
