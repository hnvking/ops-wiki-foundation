# 审批流节点调整 OA审批 建明总 需求批准后再改

## 问题描述

业务同事反馈：发起人 → 发起人部门负责人 → 项目经理 → 分线对接同步审批【生产中心对接人 / 经管中心对接人 / 姚晗 / 彭新忠】 → 业务同事、张旭明 → 邓总、任总、尹总 → 业务同事 → 曾总

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 物资、出库相关岗位
- **影响数据:** 影响审批流程节点顺序调整的需求受理。

## 原因分析

- 流程规则不清：审批流节点调整需先通过OA审批，让相关人员都批准后，再按需求修改。

## 解决方案

1. 先发起OA审批，让相关人员都批准，系统方再根据需求调整流程

## 预防措施

- 建明总不在时暂不直接调整。
- 在流程说明中明确相关规则，避免重复咨询。
