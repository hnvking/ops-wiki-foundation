# 新增审批节点 OA流程申请 建明总 配置变更

## 问题描述

业务同事反馈：加多审批节点，需要提oa流程吗

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 物资、出库相关岗位
- **影响数据:** 影响PM系统审批节点新增/调整需求的处理方式。

## 原因分析

- 流程规则不清：新增审批节点需按建明总要求走审批流程申请通过后再配置；简单调整可与建明总沟通是否直接加。

## 解决方案

1. 新增审批节点需按建明总要求走审批流程申请通过后再配置
2. 简单调整可与建明总沟通是否直接加。 结合11月11日IT 运维组说明，加节点按建明总要求需先走审批流程申请通过后才能加，或与其沟通确认简单调整是否可直接加

## 预防措施

- 在流程说明中明确相关规则，避免重复咨询。
