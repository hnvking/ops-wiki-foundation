# 工作面分配 前加签 业务同事 张旭明 孙总 节点顺序

## 问题描述

业务同事反馈：上次我去找你加的工作面分配的流程，现在有好多20号提交的还是没有过业务同事和张旭明两个人

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 物资、出库相关岗位
- **影响数据:** 影响工作面分配流程节点顺序及审批人通过情况。

## 原因分析

- 流程规则不清：前加签情况下，业务同事提交后流程还会再到其审批；业务同事与旭明审核工作面分配只能放在孙总前面，由孙总把最后一道关。

## 解决方案

1. 前加签情况下，业务同事提交后流程还会再到其审批
2. 业务同事与旭明审核工作面分配只能放在孙总前面，由孙总把最后一道关。 IT 运维组说明若选择前加签，业务同事提交后还会再到其审批
3. 后续11月1日业务同事提出其与旭明审核工作面分配只能放在孙总前面，给孙总把最后一道关

## 预防措施

- 若前加签节点位置不当，后续审批人看到已审核可能全部点同意。
- 在流程说明中明确相关规则，避免重复咨询。
