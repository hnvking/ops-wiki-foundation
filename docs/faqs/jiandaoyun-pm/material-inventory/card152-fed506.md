# 5.5.1工作面分配 业务同事 旭明 孙总 节点顺序 最后一道关

## 问题描述

业务同事反馈：5.5.1工作面分配的流程还是有问题吗？昨天才填在的业务同事 总

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 物资、出库相关岗位
- **影响数据:** 影响5.5.1工作面分配审批节点顺序。

## 原因分析

- 流程规则不清：业务同事、旭明审核工作面分配只能放在孙总前面，由孙总把最后一道关；若放在后面，后续审批人看到业务同事已审核会全部点同意。

## 解决方案

1. 业务同事、旭明审核工作面分配只能放在孙总前面，由孙总把最后一道关
2. 若放在后面，后续审批人看到业务同事已审核会全部点同意。 IT 运维组明确其与旭明审核工作面分配只能放在孙总前面，给孙总把最后一道关，并解释放在后面会导致后续审批人看到其审核后全部点同意

## 预防措施

- 审批节点顺序会影响后续审批人独立判断。
- 在流程说明中明确相关规则，避免重复咨询。
