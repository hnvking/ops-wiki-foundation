# 分包付款申请累计计量确认至本期包含已冲销暂估金额导致数值错误

## 问题描述

业务同事反馈：你是说这个数不对是吗？

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 相关业务岗位
- **影响数据:** 影响分包付款审批准确性

## 原因分析

- 数据异常：累计计量确认至本期(元)取6.3.3分包中间计量确认的本期含税实际计量确认额(元)汇总；已冲销暂估金额不应累计，实际累计应为166万，系统显示174万，差异约8万。

## 解决方案

1. 累计计量确认至本期(元)取6.3.3分包中间计量确认的本期含税实际计量确认额(元)汇总
2. 已冲销暂估金额不应累计，实际累计应为166万，系统显示174万，差异约8万 业务同事整理并确认该字段来自6.3.3分包中间计量确认表单汇总本期含税实际计量确认额(元)，因一期已冲销暂估金额被累计导致6.3.9分包付款申请累计计量确认至本期(元)虚高约8万，需删除该异常记录或调整贡献值为0

## 预防措施

- 异常数据为IT人员操作遗留，原操作人员已离职，未明确处理逻辑。
- 在流程说明中明确相关规则，避免重复咨询。
