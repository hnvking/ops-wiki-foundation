# 劳务分包合同 作废流程 第三套方案 审批链

## 问题描述

业务同事反馈：刚和邓总和孙总沟通了，采用第三套方案，仅限于劳务分包合同，其他合同暂时不可以走这个作废流程，审批人，经办人——业务同事——邓松涛——尹曼、任心刚——孙总

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 相关业务岗位
- **影响数据:** 影响劳务分包合同作废流程适用范围与审批节点。

## 原因分析

- 流程规则不清：合同作废流程仅限劳务分包合同，其他合同暂时不可走；审批链为经办人 → 业务同事 → 邓松涛 → 尹曼、任心刚 → 孙总。

## 解决方案

1. 合同作废流程仅限劳务分包合同，其他合同暂时不可走
2. 审批链为经办人 → 业务同事 → 邓松涛 → 尹曼、任心刚 → 孙总。 明确合同作废流程采用第三套方案，仅限劳务分包合同，其他合同暂不可走，审批链为经办人、业务同事、邓松涛、尹曼/任心刚、孙总

## 预防措施

- 其他合同暂时不可以走该作废流程。
- 在流程说明中明确相关规则，避免重复咨询。
