# 物资超库存

## 问题描述

用户反馈物资库存出现超库存情况，请求协助解决，业务方回复正在查询中。

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 物资、仓储相关岗位
- **影响数据:** 库存数量与实际不符，可能影响出库与盘点

## 原因分析

- 超库存可能源于入库/出库数据异常、单据重复或库存台账未及时更新，业务方正在查询确认。

## 解决方案

1. **请求业务方协助：** 向业务方反馈超库存问题，请求查询库存数据来源。
2. **核查库存台账：** 比对入库、出库、调拨单据与库存台账，定位超库存原因。
3. **必要时调整：** 确认异常后，经授权调整库存数据或修正单据。

## 预防措施

- 建立库存核查机制，定期比对单据与台账。
- 明确超库存的权限与处理流程，避免擅自调整。
