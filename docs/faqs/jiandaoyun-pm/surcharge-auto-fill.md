# 附加费自动带出

## 问题描述

用户反映在入库单选择附加费时不能自动带出价格，需确认附加费含/不含税金额的带出来源。

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 入库、物资相关岗位
- **影响数据:** 附加费金额无法自动带出，需手动填写

## 原因分析

- 选择订单明细时会从订单带出金额，但部分业务场景下订单本身不体现附加费，导致无法带出。
- 流程配置中未增设附加费金额自动带出功能。

## 解决方案

1. **确认带出来源：** 选择订单明细从订单带出金额；若订单不体现附加费，需单独配置。
2. **增设自动带出：** 在流程中增设附加费含/不含税金额字段的自动带出功能。
3. **验证：** 新增后验证入库单选择附加费时能正确带出金额。

## 预防措施

- 明确附加费金额的取数来源（订单明细 vs 附加费明细），并在流程配置中保持一致。
- 新增自动带出字段后，在测试环境验证再上线。
