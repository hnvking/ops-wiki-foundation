# 项目物资 订单查看权限 自己项目

## 问题描述

业务同事反馈：订单不是你们负责吗？那联系谁呢？项目想要查看权限，我看之前的都没有给项目开过，那不得问总部业务部门吗

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 系统用户与管理员
- **影响数据:** 影响项目物资查看订单权限的确认。

## 原因分析

- 权限配置：项目物资角色一直可以查看自己项目的订单。

## 解决方案

1. 项目物资角色一直可以查看自己项目的订单。 IT 运维组明确项目物资一直可以看自己项目的订单
