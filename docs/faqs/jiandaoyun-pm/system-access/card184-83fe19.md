# 已流转完成订单、订单名称、供应链权限

## 问题描述

业务同事反馈：想请问一下已流转完成的订单 供应链那边有权限更改一下订单名称吗？

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 系统用户与管理员
- **影响数据:** 相关单据与流程数据

## 原因分析

- 流程规则不清：已流转完成的订单目前不允许改订单名称。

## 解决方案

1. 已流转完成的订单目前不允许改订单名称 明确目前不允许更改已流转完成订单的名称

## 预防措施

- 在流程说明中明确相关规则，避免重复咨询。
