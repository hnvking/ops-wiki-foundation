# 无订单入库订单接受节点取消合同编辑权限但完全禁止选合同会影响正常订单入库

## 问题描述

业务同事反馈：昨天合同在订单不要再能选的有搞定吗

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 系统用户与管理员
- **影响数据:** 无订单入库及正常订单入库

## 原因分析

- 配置缺失：无订单入库的订单接受节点编辑权限已取消；若直接禁止在订单中选择合同，正常订单入库将无法选择合同。

## 解决方案

1. 无订单入库的订单接受节点编辑权限已取消
2. 若直接禁止在订单中选择合同，正常订单入库将无法选择合同 IT 运维组答复目前已取消无订单入库的订单接受节点编辑权限，但直接改为不能在订单里选择合同未做，因为会导致正常订单入库也选不了合同

## 预防措施

- 需另行设计判断逻辑，使直接做预入库单时可编辑，同时不影响正常订单入库选择合同。
- 在流程说明中明确相关规则，避免重复咨询。
