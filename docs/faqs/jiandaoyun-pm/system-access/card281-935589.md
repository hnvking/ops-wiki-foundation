# 碎石合同 单位 吨 立方米 单价变更 权限

## 问题描述

业务同事反馈：有一个状况，这个合同里头所有碎石，合同明细显示都是吨

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 系统用户与管理员
- **影响数据:** 相关单据与流程数据

## 原因分析

- 数据异常：合同明细单位与订单下达单位不一致需以合同单位为准修正；单价属业务数据，开发/运维不代改，由业务方自行修改并开通权限；已审批单据内容变更需领导确认。

## 解决方案

1. 合同明细单位与订单下达单位不一致需以合同单位为准修正
2. 单价属业务数据，开发/运维不代改，由业务方自行修改并开通权限
3. 已审批单据内容变更需领导确认。 业务同事已将物流、单位改过来（吨/立方），合同单价需肖环林自行修改，由业务同事开通修改权限
4. 后续修改领导审批后的合同单价需找IT 运维组确认

## 预防措施

- 领导审批后的单据内容（如合同单价）修改需先找IT 运维组确认。
- 在流程说明中明确相关规则，避免重复咨询。
