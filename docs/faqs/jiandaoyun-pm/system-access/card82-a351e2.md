# 工作面分配审批节点顺序与权限错乱的归口与处理原则

## 问题描述

业务同事反馈：这种工作面分配的流程，应该是经管和生产对接人审核完才到我们审核的么，或者我们平行生产、经管和审核的么

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 系统用户与管理员
- **影响数据:** 相关单据与流程数据

## 原因分析

- 流程规则不清：工作面分配流程以业务同事的调整要求为准；收到的这个流程的需求基本都来自供应链，包括表单内容和审批流程调整要求。

## 解决方案

1. 工作面分配流程以业务同事的调整要求为准
2. 收到的这个流程的需求基本都来自供应链，包括表单内容和审批流程调整要求 明确工作面分配流程以业务同事的调整要求为准，并由供应链归口提出表单内容与审批流程调整要求，另约生经工作面预分配同事协商审批点设计

## 预防措施

- 审批权限存在错乱，有时没有要审的、需加签，有时与其他部门平行，有时节点顺序靠前。
- 在流程说明中明确相关规则，避免重复咨询。
