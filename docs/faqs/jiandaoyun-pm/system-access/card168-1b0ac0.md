# 订单名称加-2、一期二期区分、入库区分

## 问题描述

业务同事反馈：黄经理，这些订单能不能在订单名称后面加个2呢

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 系统用户与管理员
- **影响数据:** 订单名称可编辑权限；一期/二期订单及后续入库、对账单据的区分

## 原因分析

- 权限配置：领导要求申购、订单、入库、对账都要分开；订单名称后加「-2」用于区分一期/二期，方便项目区分并按对应订单入库；切换对应权限组即可编辑修改订单名称，改完可收回权限。

## 解决方案

1. 切换到对应权限组后即可编辑修改订单名称，改完再收回权限

## 预防措施

- 仅区分订单名称未解决后续入库、对账如何分开的问题；切换权限组后部分单据点编辑仍可能无法编辑，需进一步核对。
- 在流程说明中明确相关规则，避免重复咨询。
