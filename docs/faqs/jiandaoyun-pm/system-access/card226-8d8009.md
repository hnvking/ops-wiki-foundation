# 无权限人员查看指定单据需单独开启表单外链且存在数据泄露风险

## 问题描述

业务同事反馈：[图片]如图可以，但具体表单的这个外链功能需要单独开启，你们确认下需要开启那些表单的外链功能，这个存在数据泄露的风险 业务同事 就是和OA上面的流程单据一样，有传阅功能。PM上面的，试了评论、分享都不行。PM上比如有一个单据A可以有权限看，B目前是没有权限看的这个单据的。但是A想把这个单据给B看，怎么才能实现让B也看到这个单据。

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 系统用户与管理员
- **影响数据:** 同一项目物资员之间查看彼此退库单等单据

## 原因分析

- 权限配置：外链功能需按表单单独开启，可使无权限人员查看指定单据；涉及物资出入库单、退货单、退库单、调拨单。

## 解决方案

1. 外链功能需按表单单独开启，可使无权限人员查看指定单据
2. 涉及物资出入库单、退货单、退库单、调拨单 IT 运维组答复可通过外链实现传阅，但具体表单外链功能需单独开启，需确认涉及物资出入库单、退货单、退库单、调拨单等表单，并提示存在数据泄露风险

## 预防措施

- 开启外链存在数据泄露风险。
- 在流程说明中明确相关规则，避免重复咨询。
