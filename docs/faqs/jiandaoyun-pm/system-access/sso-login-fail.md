# 简道云 PM 系统 SSO 登录失败

## 问题描述

部分用户通过企业微信工作台进入简道云 PM 系统时，扫码/点击后跳转失败，或登录页出现白屏，无法进入项目列表。错误信息类似「登录失败，请稍后重试」。

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 通过企业微信 SSO 登录的项目成员
- **影响数据:** 无数据丢失，仅登录受阻

## 原因分析

- 企业微信应用的「可信域名」或「回调地址」在系统侧未同步，导致授权回调无法携带正确 code。
- 系统侧 SSO 配置中的应用标识与企微侧不一致，签名校验失败。

## 解决方案

1. 核对企业微信应用后台的「网页授权及 JS-SDK」回调域名，确保与简道云 PM 系统 SSO 回调地址一致。
2. 核对企微应用 Secret 与系统侧 SSO 配置中的应用标识是否匹配。
3. 清理浏览器缓存后重新登录，确认跳转正常。
4. 若仍失败，查看系统 SSO 日志中的回调 code 与签名校验结果，定位具体环节。

## 预防措施

- SSO 配置变更纳入变更评审，修改前先在测试环境验证。
- 定期巡检企微应用权限与回调地址配置，与系统侧比对。
