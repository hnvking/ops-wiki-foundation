# 快捷键、下单人、项目维护

## 问题描述

业务同事反馈：黄经理，是不是项目维护的下单人不是我的话，我就没有测算和订单发起的快捷键啊，我切换啥权限都没有发起订单的快捷键

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 系统用户与管理员
- **影响数据:** 测算表与订单发起快捷键的可见性

## 原因分析

- 权限配置：测算和订单发起快捷键与项目维护的下单人及权限角色绑定；施工项目组查看权限对应发起测算，施工项目组编辑权限对应发起订单。

## 解决方案

1. 测算和订单发起快捷键与项目维护的下单人及权限角色绑定
2. 施工项目组查看权限对应发起测算，施工项目组编辑权限对应发起订单。 确认快捷键按项目维护的下单人及权限角色区分：施工项目组查看权限为发起测算、编辑权限为发起订单，自己负责的项目才有快捷键

## 预防措施

- 不同权限对应不同快捷键且不集中展示，容易被误认为账号异常。
- 在流程说明中明确相关规则，避免重复咨询。
