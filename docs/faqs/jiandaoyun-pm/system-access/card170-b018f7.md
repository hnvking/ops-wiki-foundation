# 对账单、编辑权限、订单编码

## 问题描述

业务同事反馈：对账单的编辑权限能不能给我开一下

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 系统用户与管理员
- **影响数据:** 对账单订单编码补录

## 原因分析

- 对账单上补订单编码需按表单设计先选入库类型，再选对应数据带出。

## 解决方案

1. 在对账单中先选入库类型，再选对应数据即可带出订单编码
