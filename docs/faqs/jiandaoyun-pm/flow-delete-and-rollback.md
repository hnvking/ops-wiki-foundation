# 流程单删除与回退

## 问题描述

用户反馈流程单缺少回退功能（如分包付款补录流程 PMFBFKSQ-20260805-063、PMFBFKSQ-20260803-016，金额补录错误只能否决）；或需删除指定流程单（如启光公司「分包付款申请」流程、手动结束未上流程的 PMFBFKSQ-20260904-028）。

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 发起或审批相关流程的项目/商务人员
- **影响数据:** 流程单状态与审批记录

## 原因分析

- 流程配置未开启「回退」功能，导致审批人只能否决，无法退回修改。
- 部分流程单为测试或误发起，需人工删除；部分为手动结束未上流程。
- 对账单流程已结束后，发票登记无法引用，涉及修改领导审批后单据内容，需请示上级。

## 解决方案

1. **开启回退功能：** 在流程配置中开启回退，对方重新打开审批单即可看到「回退」入口。
2. **删除流程单：** 确认表单编号后执行删除；涉及已结束未上流程的单据可直接删除。
3. **审批后单据修改：** 对已结束流程的关联单据（如发票登记引用对账单），先请示领导同意后再处理，不擅自修改。

## 预防措施

- 新流程上线前检查是否开启回退/撤回能力，并在审批节点明确退回路径。
- 删除流程单前核对表单编号与流程状态，避免误删在途单据。
- 涉及领导审批后内容修改的，先走审批再执行。
