# 部门编码 底表 PM刷数 非NC同步

## 问题描述

业务同事反馈：吧这个做底表，然后让他们选对应部门，自动出来对应部门的编码，然后传给NC是吗？

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** NC 接口相关岗位
- **影响数据:** 影响PM数据部门编码刷数。

## 原因分析

- 配置缺失：部门对应一级部门数据作为底表，选择对应部门后自动带出部门编码，用于刷PM数据，不传给NC。

## 解决方案

1. 部门对应一级部门数据作为底表，选择对应部门后自动带出部门编码，用于刷PM数据，不传给NC。 IT 运维组明确不是传给NC，而是刷PM的数据

## 预防措施

- 该数据用途不是NC同步。
- 在流程说明中明确相关规则，避免重复咨询。
