# 材料明细缺少旧物资编码、含税单价、NC同步失败

## 问题描述

业务同事反馈：材料明细缺少旧物资编码跟含税单价

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** NC 接口相关岗位
- **影响数据:** 相关单据与流程数据

## 原因分析

- 数据异常：旧物资编码与含税单价不能为空且已设为必填，缺失无法同步NC。

## 解决方案

1. 补全旧物资编码和含税单价后再同步NC

## 预防措施

- 旧物料编码和含税单价为必填项，未填写会导致同步失败。
- 在流程说明中明确相关规则，避免重复咨询。
