# 启用、流程结束、传进NC

## 问题描述

业务同事反馈：不要选启用, 流程结束传进NC会自动启用

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** NC 接口相关岗位
- **影响数据:** 相关单据与流程数据

## 原因分析

- 流程规则不清：流程结束传进NC会自动启用。

## 解决方案

1. 不要选启用，等待流程结束传进NC自动启用

## 预防措施

- 手动选启用不符合流程规则。
- 在流程说明中明确相关规则，避免重复咨询。
