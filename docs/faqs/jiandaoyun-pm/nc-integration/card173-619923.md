# 9月出入库未传NC、内部交易订单删除、接口未调用

## 问题描述

业务同事反馈：财务反馈9月大量的出入库未传NC, 其中一些是结束, 但为什么未调接口

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** NC 接口相关岗位
- **影响数据:** 9月大量出入库单据未同步NC

## 原因分析

- 外部系统对接：内部交易订单生成出入库后若订单被删除，会导致对应出入库未调接口传NC。

## 解决方案

1. 内部交易订单生成出入库后若订单被删除，会导致对应出入库未调接口传NC。 查明部分出入库为内部交易订单生成后该内部交易订单又被删除导致未推NC，需确认这类是否要推送给NC，并排查内部交易订单为何还能删除

## 预防措施

- 内部交易订单删除权限需管控；需明确这类出入库是否仍需推送NC。
- 在流程说明中明确相关规则，避免重复咨询。
