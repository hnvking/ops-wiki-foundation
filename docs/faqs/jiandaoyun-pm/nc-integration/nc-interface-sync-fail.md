# NC 接口同步失败

## 问题描述

PM 系统内各类单据（入库单、出库单、发票登记、项目间材料调拨、日记账等）在推送至 NC 系统时出现同步失败，报错信息集中在编码、单价、单位等字段。典型单据如 PMCLRKD-202609-00000187（入库单）、PMCLJXFP-202609-0075（发票登记）、PMGLFKBM-20260416-0063、PMGLFKBM-20260421-0094（未推到 NC 日记账）。

## 影响范围

- **影响系统:** 简道云 PM 系统 ↔ NC 系统
- **受影响用户:** 物资、采购、财务相关岗位
- **影响数据:** 单据无法传递至 NC，账务/日记账数据缺失

## 原因分析

笔记中出现的根因包括：

- **供应商编码不一致：** 供应商编码在 PM 与 NC 两侧不匹配，导致传递失败。
- **库存编码与 NC 不匹配：** PM 库存编码与 NC 系统对不上，导致结算信息表体字段为空报错。
- **含税单价未填写：** 单据中「含税单价」字段为空，NC 无法计算。
- **NC 缺少该单位：** 物料传 NC 不成功，报错原因为 NC 缺少该单位。
- **材料明细缺少旧物资编码/含税单价字段：** 建议将两个字段改为必填。

## 解决方案

1. **核对编码映射：** 排查供应商编码、物料编码在 PM 与 NC 两侧是否一致，协调数据对齐。
2. **补齐必填字段：** 将「旧物资编码」「含税单价」设为必填；对缺失的历史单据补录（如通过剪切粘贴含税单价）。
3. **核对单位：** 确认 NC 侧存在对应单位，缺失则补充单位档案。
4. **重推/手动同步：** 对失败单据协调接口负责人处理并重新传递，必要时手动同步。
5. **调整字段取值：** 入库单传 NC 时，有订单取常规含税金额、无订单取暂估含税金额；税率字段统一为「税率」，避免因税率不一致导致 NC 计算错误。

## 预防措施

- 新增大宗关键字段（供应商编码、物料编码、含税单价、单位）设为必填，从源头保证完整性。
- 建立 PM 与 NC 编码映射基线，变更编码前先在测试环境验证。
- 推送失败后及时跟进并保留失败单据清单，避免静默丢失。
