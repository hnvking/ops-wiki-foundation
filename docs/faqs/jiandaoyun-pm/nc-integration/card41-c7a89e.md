# 订单金额远大于入库金额、同一申购多单引用、重复明细

## 问题描述

业务同事反馈：业务同事 无订单入库金额52431元 但是带出来的订单143,676.96元 也改不了数量

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** NC 接口相关岗位
- **影响数据:** 影响该申购号下所有关联的无订单入库单及自动生成订单金额。

## 原因分析

- 数据异常：同一申购单被多个单位/多张无订单入库引用会汇总生成超量订单；源头在申购，需补申购。

## 解决方案

1. 核对申购数量及该申购是否被其他单位用于无订单入库
2. 删除超量的订单与入库单，同步删除NC数据，补申购后重做
3. 已补订单则不再走无订单入库

## 预防措施

- 单据已传NC时，删除后必须同步删除NC对应数据，否则后期同步不成功。
- 在流程说明中明确相关规则，避免重复咨询。
