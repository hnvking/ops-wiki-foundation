# 入库单供应商合同被改、订单最后节点联动、NC同步

## 问题描述

业务同事反馈：请问一下这份入库为什么你这边要把供应商跟合同给改了呀

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** NC 接口相关岗位
- **影响数据:** 五个流程的入库单供应商、合同与订单不一致，对账引用不了，且数据已同步NC

## 原因分析

- 系统缺陷：订单最后审批节点会触发系统联动，可能改写入库单的供应商、合同字段；供应商错误的数据同步到NC后会影响对账引用。

## 解决方案

1. 订单最后审批节点会触发系统联动，可能改写入库单的供应商、合同字段
2. 供应商错误的数据同步到NC后会影响对账引用。 确认五个流程中入库单的供应商、合同与订单不一致且已同步NC导致对账引用不了，IT 运维组说明系孙总作为订单最后节点触发系统联动导致名字修改，黎宇聪提出NC数据删了重传

## 预防措施

- 供应商错误的数据已传NC，需到NC核查并删除重传；批量修改入库单时易看错供应商与合同，需逐单核对订单、合同、入库三者一致。
- 在流程说明中明确相关规则，避免重复咨询。
