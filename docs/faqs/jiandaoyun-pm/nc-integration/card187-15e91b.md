# 入库单、NC接口、有无订单

## 问题描述

业务同事反馈：NC的接口要改成什么 只是根据有无订单，含税金额等的取值有变化是吧？ 有订单取常规的含税金额，无订单则取暂估的含税金额

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** NC 接口相关岗位
- **影响数据:** 相关某模块数据

## 原因分析

- 配置缺失：有订单取常规含税金额；无订单取暂估含税金额；暂估价暂不处理，先考虑无订单时传NC接口单价取暂估相关单价。

## 解决方案

1. 有订单取常规含税金额
2. 无订单取暂估含税金额
3. 暂估价暂不处理，先考虑无订单时传NC接口单价取暂估相关单价 确认入库单传NC接口按有无订单区分取值，后续明确暂估价先不处理、无订单时接口单价取暂估相关单价

## 预防措施

- 暂估价取值如无税率会导致NC计算不对。
- 在流程说明中明确相关规则，避免重复咨询。
