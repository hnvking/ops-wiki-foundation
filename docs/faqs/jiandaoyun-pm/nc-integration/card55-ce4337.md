# 订单税率非必填、入库单税率必填、零星订单

## 问题描述

业务同事反馈：这个订单里面税率不是必填，到了入库单里面税率又是必填项。那我们到了物资也填补不了啊，供应链那边下订单没有税率

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** NC 接口相关岗位
- **影响数据:** 零星订单关联的入库单同步NC

## 原因分析

- 配置缺失：订单税率设必填并做公式，入库单税率由订单带出；零星订单无合同，采购未填税率则入库单税率必填项无值。

## 解决方案

1. 采购下单时填写税率，入库单选订单后自动带出

## 预防措施

- 供应链下订单未填税率会导致物资端无法补齐税率、影响同步NC。
- 在流程说明中明确相关规则，避免重复咨询。
