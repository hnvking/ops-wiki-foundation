# 无订单入库、暂估含税单价、传NC单价为空

## 问题描述

业务同事反馈：这个入库单是无订单的 [单据编号] 之前配置了无订单时，物料单价填写的是暂估含税单价 暂估单价配置了公式等于含税单价，但是没有放出来 这个单传NC 单价是空的

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** NC 接口相关岗位
- **影响数据:** 相关单据与流程数据

## 原因分析

- 配置缺失：无订单时物料单价填写暂估含税单价；暂估单价公式等于含税单价但未放出来；审批节点发起节点要设置才会出来，优先审批节点显隐再是表单显隐；辅助字段需与是否有订单联动。

## 解决方案

1. 审批节点设置发起节点显隐
2. 重新选择一次有无订单，使明细辅助字段生效

## 预防措施

- 字段未放出来或与是否有订单未联动会导致传NC单价为空。
- 在流程说明中明确相关规则，避免重复咨询。
