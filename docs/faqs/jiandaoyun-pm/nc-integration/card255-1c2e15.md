# 供应商红冲发票 NC处理 红字采购发票

## 问题描述

业务同事反馈：请问供应商开了红冲发票过来在NC要做什么操作？

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** NC 接口相关岗位
- **影响数据:** 相关单据与流程数据

## 原因分析

- 红字采购发票需冲抵原蓝字发票，采购退库通过参照采购订单生成负数入库单。

## 解决方案

1. 方法一：反操作删除原采购发票，重新制作正确发票
2. 方法二：参照采购订单退库生成负数入库单→参照生成红字采购发票冲抵原蓝字发票→重新入库并开具正确采购发票

## 预防措施

- 在流程说明中明确相关规则，避免重复咨询。
