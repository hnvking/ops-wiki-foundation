# 销售出库 签字日期 成本计算 期间 流程配置

## 问题描述

业务同事反馈：这笔单据的销售出库单修改了签字日期到9月，成本计算还是没有显示推送

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** NC 接口相关岗位
- **影响数据:** 相关单据与流程数据

## 原因分析

- 配置缺失：销售出库单创建时间为昨天、单据日期和出库日期为8月，仅改签字日期不生效；成本计算按单据日期/出库日期/签字日期所属期间判定；业务流程创建于19年、最后修改于24年，未配置签字后自动生成成本和结算，发出商品需手工生成。

## 解决方案

1. 将单据日期、销售出库日期、签字日期全部改成9月，或删除该销售出库单重新生成在9月
2. 手工生成发出商品销售成本结转单后再计算成本

## 预防措施

- 只修改签字日期不会改变成本计算期间。
- 在流程说明中明确相关规则，避免重复咨询。
