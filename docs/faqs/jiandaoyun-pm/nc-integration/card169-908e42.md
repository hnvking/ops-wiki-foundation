# 内部交易订单、自动生成、接口关闭

## 问题描述

业务同事反馈：但是没有自动生成内部交易订单

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** NC 接口相关岗位
- **影响数据:** 直入直出/入库单的内部交易订单生成逻辑、订单类型可选值

## 原因分析

- 配置缺失：原触发规则会在入库单选择内部交易时自动生成内部交易订单；现该操作不允许，对应接口关闭，入库单订单类型字段隐藏，不再允许选择内部交易。

## 解决方案

1. 原触发规则会在入库单选择内部交易时自动生成内部交易订单
2. 现该操作不允许，对应接口关闭，入库单订单类型字段隐藏，不再允许选择内部交易。 确认原内部交易订单触发规则已不允许该操作，接口已关闭，入库单的订单类型字段直接隐藏、不允许再选内部交易

## 预防措施

- 业务人员不应再期待自动生成内部交易订单；如需内部交易需走其他流程。
- 在流程说明中明确相关规则，避免重复咨询。
