# 直入直出NC同步接口增加失败重试

## 问题描述

业务同事反馈：直入直出到出库单同步NC接口改为第一次如果不成功会再进行一次同步，后期再观察下是否还会出现出库先走完，入库还没到NC导致传递不成功的情况

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** NC 接口相关岗位
- **影响数据:** 直入直出相关的出库单NC同步

## 原因分析

- 外部系统对接：出库先走完、入库还没到NC会导致传递不成功，接口首次失败后重试一次。

## 解决方案

1. 出库先走完、入库还没到NC会导致传递不成功，接口首次失败后重试一次。 直入直出到出库单的NC同步接口已改为首次失败后再重试一次同步，后续观察出库先完成、入库未到NC导致传递不成功的情况

## 预防措施

- 需持续观察是否仍出现出库先完成导致同步失败。
- 在流程说明中明确相关规则，避免重复咨询。
