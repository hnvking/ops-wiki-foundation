# 退货 销售成本结转单 取不到单价 负数链路

## 问题描述

业务同事反馈：王老师：这张取不到单价的销售成本结转单为什么不能手工维护一个单价呢？麻烦帮忙看看有没有什么办法解决。

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** NC 接口相关岗位
- **影响数据:** 涉及销售退货、销售出库、销售成本结转及收发存汇总表数据一致性。

## 原因分析

- 流程规则不清：销售成本结转单贷方单据单价依据借方单据单价计算；客户先退货再重新出库时，退货要通过退货订单生成销售出库，不能直接在正数订单上手动改数量；NC不能直接从出库单做退库，必须先做负数的销售订单—发货单—销售出库；发货单数量不体现在收发存汇总表，只有其后的销售出库单才真正减少库存量；发货单数量与销售出库单数量原则上要一致，建议增加同一销售订单退货负数不能大于正数销售数量的防火墙。

## 解决方案

1. 按负数销售订单→负数发货单→负数销售出库完成退货
2. 正数出库按销售发票生成销售成本结转单（确认开票后的发出商品贷方单据）
3. 如需调整期间，将退库的销售出库删除后做到10月，且正数出库单也需一并删除否则无数量可出

## 预防措施

- 在流程说明中明确相关规则，避免重复咨询。
