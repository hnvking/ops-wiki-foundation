# 同步NC、提交、流程结束

## 问题描述

业务同事反馈：要同步NC才可以流程结束 要他点同步NC成功后才可以提交

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** NC 接口相关岗位
- **影响数据:** 相关单据与流程数据

## 原因分析

- 用户操作：同步NC成功后才可提交，要同步NC才可流程结束。

## 解决方案

1. 点同步NC，成功后提交，流程方可结束

## 预防措施

- 未同步NC成功不能提交、流程不能结束。
- 在流程说明中明确相关规则，避免重复咨询。
