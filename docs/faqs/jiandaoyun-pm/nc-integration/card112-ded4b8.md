# 预入库单价 合同价 车型 镇 历史价格 订单价格刷新 财务做账

## 问题描述

业务同事反馈：之前建明总说的预入库取合同单价，是取这个单价作为预估单价对吧

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** NC 接口相关岗位
- **影响数据:** 影响预入库材料预估单价、合同价取值、财务做账金额准确性。

## 原因分析

- 数据异常：有合同按合同价；根据选择的车型和镇确定合同价；但订单车辆类型字段基本为空。无订单入库用于不具备做订单条件的情况，合同未签订时单价不确定，当时从历史价格捞取，后续要用订单价格刷过去。

## 解决方案

1. 有合同按合同价
2. 根据选择的车型和镇确定合同价
3. 但订单车辆类型字段基本为空。无订单入库用于不具备做订单条件的情况，合同未签订时单价不确定，当时从历史价格捞取，后续要用订单价格刷过去。 10月30日IT 运维组确认预入库材料单价按建明总说的做，并说明无订单入库针对不具备做订单条件，合同未签订时单价不确定，历史价金额推财务做账不对，需按订单价格刷新

## 预防措施

- 历史价格捞出的金额推给财务做账本身不正确；车辆类型字段多为空会影响按车型/镇取合同价；如需改无订单入库方案，需要沟通建明总。
- 在流程说明中明确相关规则，避免重复咨询。
