# 无订单入库后补出采购订单导致匹配数量变化及删单或重走订单处理建议

## 问题描述

业务同事反馈：无订单入库 是这样的 我入的数量是正确的 到了供应连哪里 一批匹配订单 数量就变成订单数量

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** NC 接口相关岗位
- **影响数据:** 涉及PM预入库单、NC单据及已走完审批的采购订单

## 原因分析

- 流程规则不清：前期无订单按要求做无订单入库，后续11月10号左右才出采购订单；供应链一批匹配订单后数量变成订单数量；部分审批已走完且采购订单已生成，删除会牵连PM、NC和采购订单。

## 解决方案

1. 前期无订单按要求做无订单入库，后续11月10号左右才出采购订单
2. 供应链一批匹配订单后数量变成订单数量
3. 部分审批已走完且采购订单已生成，删除会牵连PM、NC和采购订单 业务同事给出可配合删除PM单据但NC需自行处理、或沟通供应链删除对应采购订单并重新走合适量采购订单两种办法

## 预防措施

- 删除后NC也需删单且NC侧需自行处理；较简单办法是沟通供应链删除对应采购订单再重新走合适量采购订单。
- 在流程说明中明确相关规则，避免重复咨询。
