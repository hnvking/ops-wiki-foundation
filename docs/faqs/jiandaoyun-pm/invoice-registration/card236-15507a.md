# 入库单税率含税金额不含税金额引用对账单缺失及合同信息不一致

## 问题描述

业务同事反馈：黄工，麻烦帮忙看下，我入库单上面有税率，含税金额和不含税金额，引用到对账单上面就没有了，这是咋回事

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 相关业务岗位
- **影响数据:** 相关单据与流程数据

## 原因分析

- 数据异常：入库单税率、含税金额、不含税金额引用到对账单缺失与入库单有合同、对账单无合同有关；入库单选订单未选合同，但比价环节及订单已有合同。

## 解决方案

1. 入库单税率、含税金额、不含税金额引用到对账单缺失与入库单有合同、对账单无合同有关
2. 入库单选订单未选合同，但比价环节及订单已有合同 业务同事发现入库单写有合同而对账单又没有合同，IT 运维组说明入库单选的是订单未选合同，且从供应链比价环节开始就有合同、出的订单也有合同

## 预防措施

- 在流程说明中明确相关规则，避免重复咨询。
