# 字段带出 订单类型 物资类型 单价类型 二级类别 供应商 税率 申购单编号 已下

## 问题描述

业务同事反馈：1、订单类型 跟 物资类型 里面类容都不一样，不能带； 2、单价类型 跟入库物资类型（入库单就没有），不能带； 3、订单的二级类别 单一，入库单物料二级类型可能不同（禁忌多对1了），不能带； 4、供应商、税率由乙方合同带出，存在多对1的关系，不能带 5、申购单编号 需要有测试表才能多选，不能带； 6、申购已下单量数据在申购单创建后自动生成的项目需用申购明细里…

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 相关业务岗位
- **影响数据:** 影响预入库/入库材料明细字段向采购订单带出配置。

## 原因分析

- 配置缺失：订单类型与物资类型内容不同不能带；单价类型与入库物资类型不对应且入库单无该字段；订单二级类别单一而入库单物料二级类型可能不同，存在多对一禁忌；供应商、税率由乙方合同带出且存在多对一不能带；申购单编号需测试表才能多选；申购已下单量为申购单创建后自动生成、汇总后被引用，存在多对一不能带出。

## 解决方案

1. 订单类型与物资类型内容不同不能带
2. 单价类型与入库物资类型不对应且入库单无该字段
3. 订单二级类别单一而入库单物料二级类型可能不同，存在多对一禁忌
4. 供应商、税率由乙方合同带出且存在多对一不能带

## 预防措施

- 多对一关系字段不能反向或汇总带入订单，需避免订单字段被错误覆盖。
- 在流程说明中明确相关规则，避免重复咨询。
