# 请购单关闭 采购订单 入库 开票 付款

## 问题描述

业务同事反馈：正常转出采购订单，但采购交货未完情况下，手工关闭请购单，会影响后面采购入库吗？

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 相关业务岗位
- **影响数据:** 相关某模块数据

## 原因分析

- 流程规则不清：影响下游入库/开票/付款的是采购订单关闭状态，请购单手工关闭不传导至已生成的采购订单。

## 解决方案

1. 影响下游入库/开票/付款的是采购订单关闭状态，请购单手工关闭不传导至已生成的采购订单。 手工关闭请购单不会影响下游已生成采购订单后续的入库、开票和付款，只有采购订单关闭才会影响

## 预防措施

- 在流程说明中明确相关规则，避免重复咨询。
