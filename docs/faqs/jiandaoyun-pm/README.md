# 简道云 PM 系统 FAQ

本目录收录简道云 PM 系统的运维问题。

- **物理归档**仍按「系统 → 表单」两级：每个表单一个子目录，问题文件放在对应表单目录下。
- **导航呈现**按「问题类型」分组，与企微表格「问题类型」字段同一口径；侧边栏 5.1 即按此分组展开。

新增问题时在 frontmatter 填写 `related_system: 简道云 PM 系统`、`related_form: <表单标识>`（必填）、`problem_type: <问题类型>`（可选），并保存到 `faqs/jiandaoyun-pm/<表单标识>/<问题>.md`。
