# 权限开通与回收

## 问题描述

用户需要开通或回收 PM 系统内的各类权限：查看权限（如材料退库单、分包付款申请）、导入权限（合同、物资档案、集采合同）、发起/填报权限（7.4 模块、生产管理模块）、数据管理权限，以及临时开放/收回流程表单编辑权限等。

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 各项目、商务、物资、供应链岗位成员
- **影响数据:** 无数据影响，仅功能访问范围变化

## 原因分析

- 新成员加入或岗位调整需开通对应模块权限。
- 流程表单编辑权限默认收回，需临时开放以修改订单有效期等。
- 查看权限缺失导致用户无法查看数据（如材料退库单、启光分包付款申请）。

## 解决方案

1. **开通查看权限：** 为指定用户在对应表单/模块开通查看权限，并协助刷新页面验证。
2. **开通导入权限：** 在对应表单（如合同、物资档案、集采合同）开通导入权限，必要时设置字段必填（如客户名称）。
3. **开通发起/填报权限：** 为部门成员开通指定模块（如 7.4 模块）的添加与发起权限。
4. **临时开放编辑：** 修改字段前临时开放编辑权限，完成后回收；收回第七大项所有流程表单编辑权限。
5. **数据管理权限：** 为多人开通数据管理权限，并临时开通同步 NC 权限。

## 预防措施

- 建立权限清单，记录每个角色的权限范围，避免临时授权遗留。
- 临时开放的编辑权限应在操作完成后及时回收并记录。
- 新增成员按岗位模板统一配置，减少逐项开通。
