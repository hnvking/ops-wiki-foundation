# 分包付款申请累计计量金额异常

## 问题描述

用户提交「6.3.9分包付款申请」流程时，发现「累计计量确认至本期(元)」字段自动带出的金额与实际应计金额不符。系统累计金额为 174 万元，实际应累计为 166 万元，差异约 8 万元。

## 影响范围

- **影响系统:** 简道云 PM 系统
- **受影响用户:** 发起分包付款申请的商务/项目人员
- **影响数据:** 付款审批金额计算失真，影响付款审批的准确性

## 原因分析

- 「累计计量确认至本期(元)」字段的数据来自「6.3.3分包中间计量确认」表单的汇总字段「本期含税实际计量确认额(元)」。
- 该数据源中混入了一条约 8 万元的**已冲销暂估记录**，被错误地累计到总金额中。
- 经确认，该异常数据由已离职的 IT 人员遗留操作录入，原因不明。

## 解决方案

1. **确认权限与责任：** 删除此类业务数据须先获得业务方领导明确授权，IT 支持方不得擅自删除。
2. **业务方确认：** 提问方向商务经理请示并获同意后，反馈给 IT 支持方。
3. **执行数据清理：** 在「6.3.3分包中间计量确认」表单中删除包含已冲销暂估金额在内的 2 条异常记录。
4. **处理数据污染：** 删除异常数据后，「6.3.9分包付款申请」中的「累计已申请金额」字段出现翻倍等异常，判断为**嵌套引用**导致的数据污染。
5. **重建流程：** 保存现有数据后，删除当前异常的「6.3.9分包付款申请」流程并重新新建，新流程数据恢复正常。

## 预防措施

- 删除业务数据前，一律先经业务方领导确认，保留审批痕迹。
- 对历史离职人员遗留的异常数据建立定期核查机制，重点检查汇总类字段。
- 涉及嵌套引用的汇总字段，调整数据源后应连带校验下游引用表单。
