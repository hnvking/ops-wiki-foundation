# 项目管理服务

## 概述

项目管理服务是 IT 部门依托简道云 PM 系统为全体项目相关人员提供的一站式项目管理能力，覆盖从立项申请、任务分配、进度跟踪、里程碑管理到验收结项的完整生命周期。服务对象包括项目负责人、PMO、各业务部门协作成员及管理层。

## 服务负责人

| 角色         | 姓名/团队       |
|-------------|----------------|
| 首要负责人   | 项目管理团队    |
| 备份联系人   | IT 运维组       |
| 升级路径     | 项目经理 → 项目管理团队 → IT 运维组 |

## SLA / 服务水平期望

- **可用性目标:** 99.9%（工作日 9-18 点）
- **响应时间:** 4 小时（P2 及以上事件）
- **解决时间:** 1 个工作日（一般问题）

## 支持时间

周一至周五 9-18 点，法定节假日除外。紧急问题可联系 IT 运维组值班。

## 用户/受众

- 项目负责人与项目经理
- PMO 及跨部门协作成员
- 需要查看项目进度与资源情况的管理层

## 依赖

- 简道云 PM 系统（[简道云 PM 系统](../systems/jiandaoyun-pm-system.md)）
- 企业微信（身份认证与消息通知）
- 简道云低代码平台
