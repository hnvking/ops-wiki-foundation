# OA 系统

## 概述

OA 系统是团队基于简道云（Jiandaoyun）低代码平台搭建的办公自动化系统，用于支撑企业内部行政审批流程：从请假申请、用章审批、公文流转到报销审批。系统面向全体员工、行政管理团队及跨部门审批人。

## 技术详情

| 字段       | 值                                      |
|-----------|----------------------------------------|
| 厂商       | 简道云                                  |
| 版本       | SaaS（厂商托管）                        |
| 托管       | 云（SaaS）                              |
| 认证       | SSO（通过企业微信扫码登录）             |
| URL / 访问入口 | https://example.jiandaoyun.com（示例） |

## 负责人与支持

| 角色         | 姓名/团队                          |
|-------------|-----------------------------------|
| 系统负责人   | 行政管理团队                        |
| 厂商支持     | 简道云官方客服                      |
| 内部支持     | 行政管理团队 + IT 运维组            |

## 依赖

- 企业微信：身份认证与消息通知
- 简道云平台：低代码应用托管

## 集成

- 企业微信通讯录与扫码登录（SSO）
- 审批结果自动推送到企业微信群（示例）

## 备份与恢复

- **备份频率:** 厂商管理，平台持续备份
- **恢复流程:** 联系简道云官方支持恢复
- **RPO / RTO:** RPO 1小时 / RTO 4小时（按厂商 SLA）
