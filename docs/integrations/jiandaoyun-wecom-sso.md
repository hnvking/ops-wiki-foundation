# 企业微信 SSO 集成

## 概述

该集成实现简道云 PM 系统与企业微信之间的单点登录与消息通知能力。员工使用企业微信扫码即可登录简道云 PM 系统，无需单独维护账号密码；同时项目相关通知（任务分配、进度提醒、周报推送）通过企业微信应用消息触达用户。

## 涉及的系统

| 系统               | 角色       | 方向   |
|-------------------|-----------|-------|
| 简道云 PM 系统     | 依赖方     | 双向   |
| 企业微信           | 身份提供方 | 双向   |

## 技术详情

| 字段       | 值                              |
|-----------|--------------------------------|
| 协议       | OAuth 2.0 / OIDC              |
| 频率       | 实时（登录时校验）              |
| 认证方式   | 企业微信扫码授权               |
| 错误处理   | 校验失败则跳转企业微信重新授权  |

## 数据流

1. 用户在简道云 PM 系统点击「企业微信登录」。
2. 系统重定向到企业微信授权页，用户扫码确认身份。
3. 企业微信返回授权码，系统换取用户信息并建立会话。
4. 项目事件（任务分配、进度更新）通过企业微信应用消息实时推送。

## 负责人与支持

| 角色         | 姓名/团队       |
|-------------|----------------|
| 集成负责人   | IT 运维组       |
| 厂商联系人   | 简道云官方客服 + 企业微信服务商 |

## 故障与恢复

- **如果失败会怎样:** 用户无法登录，或收不到项目通知。
- **如何检测故障:** 登录失败率上升、企业微信回调报错、用户反馈收不到消息。
- **恢复步骤:** 核对企业微信应用配置（CorpID、Secret、回调地址），确认回调 URL 可达后重新授权；必要时联系厂商支持。
