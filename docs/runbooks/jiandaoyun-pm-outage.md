# 简道云 PM 系统故障应急手册

## 摘要

本手册覆盖简道云 PM 系统发生不可访问、SSO 登录异常或项目数据异常等事件时的检测、响应、升级与恢复流程，适用于 IT 运维组与项目管理团队。

## 严重级别

- **级别:** High（高）
- **影响:** 全体项目人员无法使用项目管理系统，项目进度跟踪与汇报中断
- **受影响用户:** 项目负责人、PMO、跨部门协作成员

## 检测

- 用户反馈无法打开简道云 PM 系统或登录失败
- 企业微信扫码后无法进入系统
- 监控告警：接口响应超时、5xx 错误率上升
- 项目数据异常（如任务丢失、进度不同步）

## 立即响应

1. 确认影响范围：统计受影响用户、部门与项目。
2. 判断故障类型：登录失败 / 页面不可访问 / 数据异常。
3. 检查网络与 DNS：确认公司内网到简道云域名可达。
4. 联系简道云官方支持并同步故障信息，索取工单号。
5. 若为企业微信 SSO 问题，核对企业微信应用配置与回调地址。

## 升级路径

| 级别 | 联系人         | 方式                     |
|------|--------------|-------------------------|
| 一级 | IT 运维组值班 | 即时响应                 |
| 二级 | 项目管理团队  | 电话 / 企业微信          |
| 三级 | 部门负责人    | 电话 / 邮件              |

## 沟通

- **内部通知:** 立即在企业微信群同步故障与预计恢复时间。
- **面向用户的沟通:** 通过企业微信应用消息/公告告知项目人员。
- **状态页更新:** 如有状态页，发布「服务降级 / 维护中」状态。

## 解决步骤

1. 若为网络问题：排查内网出口、DNS、防火墙策略。
2. 若为平台侧故障：跟进简道云官方工单，等待厂商恢复。
3. 若为 SSO 问题：核对 CorpID、Secret、回调地址，必要时重新授权。
4. 恢复后验证：登录、项目列表、任务详情、周报推送逐一验证。
5. 通知用户恢复，关闭事件。
